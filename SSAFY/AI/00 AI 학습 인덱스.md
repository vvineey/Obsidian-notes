# AI 학습 인덱스

> [!summary] 관리 원칙
> AI 실습은 다섯 개의 주제별 저장소 단위로 관리한다. 각 저장소는 `실습`과 `개념`에 동일한 slug의 폴더를 가지며, 실습 가이드는 필요한 개념 노트와 양방향으로 연결한다.

## 저장소 구성

| 저장소 | 학습 영역 | 상태 |
|---|---|---|
| `ml-pytorch-foundations` | EDA, 전통 ML, PyTorch, Perceptron, MLP | 진행 중 |
| `nlp-llm-foundations` | 토큰화, 임베딩, Attention, 합성 데이터 | 예정 |
| `vision-generative-models` | CNN 전이학습, 이미지 생성과 평가 | 예정 |
| `rag-agent-systems` | RAG, ReAct, Multi-Agent | 예정 |
| `efficient-llm-engineering` | PEFT, QLoRA, Quantization | 예정 |
