# 전이학습과 이미지 분류 모델 활용

> [!summary]
> 전이학습은 대규모 데이터로 미리 학습한 모델의 표현 능력을 새로운 문제에 재사용하는 방법이다. 이미지 분류에서는 사전 학습된 backbone을 특징 추출기로 사용하고, 새로운 데이터의 클래스 수에 맞춰 classification head를 교체한다. 데이터와 목적에 따라 head만 학습하는 Linear Probing, 일부 또는 전체 모델을 조정하는 Fine-tuning을 선택한다.

## 학습 목표

- 사전 학습된 특징이 새로운 이미지 분류 문제에 재사용될 수 있는 이유를 설명한다.
- backbone과 classification head의 역할을 구분한다.
- Linear Probing과 Fine-tuning의 학습 범위와 장단점을 비교한다.
- 전처리, 데이터 증강, 학습률이 전이학습 성능에 미치는 영향을 이해한다.
- CNN 기반 ResNet과 Transformer 기반 ViT의 이미지 처리 방식을 비교한다.

## 1. 전이학습이 필요한 이유

딥러닝 모델을 처음부터 학습하려면 많은 데이터와 계산 자원이 필요하다. 그러나 이미지 모델의 앞부분은 특정 클래스에만 필요한 정보가 아니라 엣지, 색상 변화, 질감, 윤곽처럼 여러 시각 문제에서 공통으로 쓰이는 특징을 학습한다.

ImageNet처럼 큰 데이터셋에서 학습된 모델은 이러한 일반적인 시각 표현을 이미 가지고 있다. 새로운 데이터셋에서는 이 표현을 재사용하고, 새로운 클래스 구분에 필요한 부분만 추가로 학습할 수 있다.

전이학습의 주요 효과는 다음과 같다.

- 적은 데이터로도 비교적 높은 성능을 얻을 수 있다.
- 무작위 초기화 모델보다 빠르게 수렴할 수 있다.
- 학습해야 할 파라미터를 줄이면 계산량과 과적합 위험이 감소한다.
- 목표 데이터의 특성에 맞춰 일부 또는 전체 표현을 다시 조정할 수 있다.

## 2. Backbone과 Classification Head

이미지 분류 모델은 크게 두 부분으로 나눌 수 있다.

```text
입력 이미지 → Backbone → 특징 벡터 → Classification Head → 클래스별 logits
```

### Backbone

이미지에서 유용한 특징을 추출한다. ResNet-18에서는 합성곱 계층과 residual block이 이 역할을 담당한다. 앞쪽 계층은 엣지와 색상 같은 저수준 특징을, 뒤쪽 계층은 형태와 객체 구성 같은 고수준 특징을 주로 표현한다.

### Classification Head

backbone이 만든 특징 벡터를 클래스별 점수로 변환한다. ImageNet용 ResNet-18의 마지막 `fc`는 1,000개 클래스를 출력하므로, CIFAR-10에 적용할 때는 10개 출력을 갖는 계층으로 교체해야 한다.

```python
model.fc = nn.Linear(model.fc.in_features, 10)
```

배치 크기가 256이라면 대표적인 텐서 흐름은 다음과 같다.

```text
[256, 3, 224, 224] → ResNet backbone → [256, 512] → fc → [256, 10]
```

마지막 `[256, 10]`은 확률이 아니라 클래스별 원시 점수인 logits이다.

## 3. Linear Probing

Linear Probing은 사전 학습된 backbone을 고정하고 새 classification head만 학습하는 전략이다.

```python
for name, param in model.named_parameters():
    if "fc" not in name:
        param.requires_grad = False

optimizer = optim.SGD(model.fc.parameters(), lr=0.001)
```

### 특징

- 학습 대상이 적어 빠르고 메모리 사용량이 작다.
- 사전 학습 표현을 그대로 보존한다.
- 데이터가 적을 때 과적합 위험이 비교적 낮다.
- 원본 데이터와 목표 데이터의 차이가 크면 성능에 한계가 생길 수 있다.

`requires_grad=False`는 해당 파라미터에 대한 gradient 계산과 가중치 갱신을 막는다. 순전파 자체를 막는 것은 아니므로, 입력은 여전히 backbone을 통과하여 특징 벡터로 변환된다.

## 4. Fine-tuning

Fine-tuning은 사전 학습된 파라미터의 일부 또는 전체를 목표 데이터에 맞게 추가 학습하는 전략이다.

```python
for param in model.parameters():
    param.requires_grad = True

optimizer = optim.SGD(model.parameters(), lr=0.0005)
```

### 범위에 따른 구분

| 방식 | 학습 범위 | 특징 |
|---|---|---|
| Linear Probing | head만 | 빠른 기준 성능 확인에 적합 |
| Partial Fine-tuning | 상위 backbone 계층과 head | 계산량과 적응력의 절충 |
| Full Fine-tuning | 전체 모델 | 높은 적응력, 큰 계산량과 과적합 위험 |

Fine-tuning에서는 일반적으로 Linear Probing보다 낮은 학습률을 사용한다. 큰 학습률은 사전 학습된 유용한 표현을 급격하게 변화시켜 성능을 떨어뜨릴 수 있기 때문이다.

> [!warning]
> 동결을 해제한 뒤에는 옵티마이저도 다시 생성해야 한다. 기존 옵티마이저가 `model.fc.parameters()`만 참조한다면 backbone의 `requires_grad`를 `True`로 바꾸어도 backbone은 갱신되지 않는다.

## 5. 이미지 전처리와 데이터 증강

### 리사이즈

CIFAR-10 이미지는 32×32이지만, ImageNet 기반 ResNet과 ViT는 일반적으로 224×224 입력을 사용한다. 따라서 모델의 입력 계약에 맞도록 크기를 변환한다.

### 텐서 변환과 정규화

대표적인 순서는 다음과 같다.

```text
Resize → ToTensor → Normalize
```

정규화는 채널별로 입력 분포를 조정하여 최적화를 안정적으로 만든다. 평균과 표준편차를 직접 계산할 때는 테스트 데이터가 아니라 학습 데이터만 사용해야 한다. 테스트 데이터의 통계가 학습 과정에 반영되면 데이터 누수가 발생한다.

사전 학습 모델에서는 두 기준을 구분할 필요가 있다.

- 목표 데이터 통계 사용: 현재 데이터 분포에 맞춘다.
- 사전 학습 당시 통계 사용: 모델이 학습할 때 본 입력 분포와 일치시킨다.

두 선택 중 어느 것이 항상 우수한 것은 아니므로 검증 데이터로 비교할 수 있다.

### 데이터 증강

데이터 증강은 의미를 유지하는 무작위 변환으로 학습 표본의 다양성을 높인다.

```python
transforms.RandomCrop(32, padding=4)
transforms.RandomHorizontalFlip(p=0.5)
```

- `RandomCrop`: 물체 위치 변화에 대한 강건성을 높인다.
- `RandomHorizontalFlip`: 좌우 방향 변화에도 같은 클래스를 인식하도록 돕는다.

증강은 학습 데이터에만 적용한다. 테스트 입력이 매번 달라지면 모델 간 평가 조건이 일정하지 않게 된다.

## 6. 최적화와 학습률 조정

다중 클래스 분류에서는 `CrossEntropyLoss`를 사용한다.

```python
criterion = nn.CrossEntropyLoss()
```

이 손실 함수에는 softmax를 직접 적용한 값이 아니라 모델의 logits와 정수 클래스 레이블을 전달한다.

기본 학습 순서는 다음과 같다.

```python
optimizer.zero_grad()
outputs = model(xb)
loss = criterion(outputs, yb)
loss.backward()
optimizer.step()
```

- `zero_grad`: 이전 미니배치의 gradient 제거
- forward: 예측 logits 계산
- loss: 예측과 정답 차이 계산
- backward: 각 파라미터의 gradient 계산
- step: 학습 가능한 파라미터 갱신

### 학습률 스케줄러

`StepLR`은 정해진 에포크마다 학습률에 일정 비율을 곱한다.

```python
scheduler = optim.lr_scheduler.StepLR(
    optimizer,
    step_size=5,
    gamma=0.1,
)
```

초반에는 비교적 큰 보폭으로 탐색하고, 후반에는 작은 보폭으로 파라미터를 세밀하게 조정할 수 있다. 에포크 단위 스케줄러라면 일반적으로 에포크 학습이 끝난 뒤 `scheduler.step()`을 호출한다.

## 7. 모델 평가

평가 시에는 학습 모드와 gradient 기록을 모두 제어한다.

```python
model.eval()
with torch.no_grad():
    outputs = model(xb)
    predicted = outputs.argmax(dim=1)
```

- `model.eval()`: Dropout과 Batch Normalization을 평가 방식으로 전환
- `torch.no_grad()`: gradient 기록을 중단하여 메모리와 계산량 절약
- `argmax(dim=1)`: 클래스 점수가 가장 큰 인덱스를 예측으로 선택

Linear Probing과 Fine-tuning을 비교할 때는 동일한 테스트 데이터와 전처리, 같은 정확도 계산법을 사용해야 한다.

> [!note]
> `requires_grad=False`와 `model.eval()`은 목적이 다르다. 전자는 파라미터 gradient를 막고, 후자는 Batch Normalization과 Dropout의 동작 방식을 바꾼다.

## 8. Vision Transformer의 전이학습

Vision Transformer는 이미지를 패치로 나누고 각 패치를 NLP의 토큰처럼 처리한다.

224×224 이미지를 16×16 패치로 나누면 196개 패치가 생성된다.

```text
이미지 → 패치 분할 → 패치 임베딩 → 위치 정보 추가
→ Transformer Encoder → CLS 표현 → 분류 Head
```

### CNN과 ViT 비교

| 구분 | CNN | ViT |
|---|---|---|
| 핵심 연산 | Convolution | Self-Attention |
| 기본 특징 | 인접 영역의 지역 패턴 | 패치 사이의 전역 관계 |
| 귀납적 편향 | locality가 강함 | 상대적으로 약함 |
| 데이터 의존성 | 비교적 적은 데이터에도 강함 | 대규모 사전 학습 효과가 큼 |

Hugging Face에서는 전처리기와 모델을 같은 체크포인트에서 불러와 입력 규칙을 맞춘다.

```python
image_processor = ViTImageProcessor.from_pretrained(model_name)
vit_model = ViTForImageClassification.from_pretrained(model_name)

inputs = image_processor(images=images, return_tensors="pt")
outputs = vit_model(**inputs)
predicted = outputs.logits.argmax(dim=1)
```

- `ViTImageProcessor`: 리사이즈, 정규화, 배치 텐서 생성을 담당한다.
- `ViTForImageClassification`: 전처리된 `pixel_values`를 받아 logits를 반환한다.
- `pipeline("image-classification")`: 전처리, 추론, 후처리를 간단한 인터페이스로 묶는다.

## 9. 자주 혼동하는 지점

### 동결하면 순전파도 멈추는가?

아니다. 순전파로 특징은 계속 계산한다. 다만 동결된 파라미터의 gradient와 가중치 업데이트가 생략된다.

### Fine-tuning은 항상 더 좋은가?

아니다. 데이터가 매우 적거나 학습률이 너무 크면 과적합 또는 사전 학습 표현의 손상이 발생할 수 있다.

### head만 교체하면 자동으로 head만 학습되는가?

아니다. backbone의 `requires_grad`와 옵티마이저가 참조하는 파라미터를 모두 확인해야 한다.

### `model.train()`을 호출하면 동결된 Batch Normalization도 완전히 고정되는가?

아니다. affine 파라미터의 gradient는 막을 수 있지만 running mean과 running variance는 학습 모드에서 갱신될 수 있다. 엄격한 고정 특징 추출이 필요하면 Batch Normalization의 모드도 별도로 고려해야 한다.

### 학습 손실이 낮으면 테스트 정확도도 반드시 높은가?

아니다. 학습 손실만 감소하고 테스트 성능이 개선되지 않으면 과적합을 의심해야 한다. 학습과 검증 지표를 함께 비교해야 한다.
