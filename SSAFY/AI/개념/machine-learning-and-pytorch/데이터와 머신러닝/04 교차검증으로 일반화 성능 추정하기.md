# 04 교차검증으로 일반화 성능 추정하기

## 1. 모델 평가와 일반화 성능

![[CS/AI/일반화와 과적합#핵심 정리]]

머신러닝의 목표는 학습 데이터에서만 높은 점수를 얻는 것이 아니다. 학습에 사용하지 않은 새로운 데이터에서도 예측 성능을 유지해야 한다. 이 능력을 **일반화**라고 한다.

현실에서 앞으로 들어올 모든 데이터를 미리 확인할 수는 없으므로, 학습에 사용하지 않은 데이터를 이용해 일반화 성능을 추정한다.

### 일반화 오차와 테스트 오차

- 일반화 오차는 모델이 앞으로 만나게 될 데이터 분포 전체에서 발생시키는 평균 오차다.
- 테스트 오차는 학습에 사용하지 않은 테스트 표본에서 측정한 오차다.
- 테스트 오차는 일반화 오차 그 자체가 아니라 한정된 표본으로 추정한 값이다.

테스트 데이터 구성에 따라 결과가 달라질 수 있으므로 테스트 점수 하나를 절대적인 성능으로 해석하면 안 된다.

## 2. 학습 오차와 테스트 오차

| 구분 | 측정 대상 | 의미 |
| --- | --- | --- |
| 학습 오차 | 모델 학습에 사용한 데이터 | 학습 데이터를 얼마나 잘 맞혔는지 |
| 검증 오차 | 모델 선택에 사용하는 데이터 | 어떤 모델과 설정이 더 나은지 비교 |
| 테스트 오차 | 모든 선택이 끝난 뒤 남겨 둔 데이터 | 최종 일반화 성능 추정 |

모델 복잡도가 높아질수록 학습 오차는 보통 계속 감소한다. 반면 테스트 오차는 처음에는 감소하다가 모델이 학습 데이터의 잡음까지 외우기 시작하면 다시 증가할 수 있다. 따라서 학습 오차가 가장 작은 모델이 일반화 성능까지 가장 좋은 것은 아니다.

## 3. 과적합과 과소적합

### 과소적합

모델이 너무 단순해 데이터의 중요한 패턴을 충분히 학습하지 못한 상태다. 학습 오차와 검증·테스트 오차가 모두 높다.

### 과적합

모델이 일반적인 패턴뿐 아니라 학습 데이터에 포함된 잡음과 우연한 특징까지 외운 상태다. 학습 오차는 매우 낮지만 검증·테스트 오차가 상대적으로 높다.

| 상태 | 학습 오차 | 검증·테스트 오차 | 특징 |
| --- | ---: | ---: | --- |
| 과소적합 | 높음 | 높음 | 중요한 패턴도 학습하지 못함 |
| 적절한 학습 | 낮음 | 낮음 | 새로운 데이터에서도 성능 유지 |
| 과적합 | 매우 낮음 | 높음 | 학습 데이터의 잡음까지 외움 |

교차검증은 과적합을 직접 없애는 방법이 아니다. 새로운 데이터에서의 성능을 더 안정적으로 추정해 과적합된 모델을 선택할 가능성을 줄이는 평가 방법이다.

## 4. 학습·검증·테스트 데이터

### 학습 데이터

모델의 파라미터를 학습하는 데 사용한다.

### 검증 데이터

모델 종류, 모델 복잡도, 하이퍼파라미터, 전처리 방법과 학습 중단 시점 등을 선택하는 데 사용한다.

### 테스트 데이터

모든 선택이 끝난 뒤 최종 성능을 한 번 평가하는 데 사용한다.

테스트 데이터를 반복해서 확인하며 모델을 수정하면 테스트 정보가 모델 선택 과정에 들어간다. 그러면 테스트 데이터는 더 이상 처음 보는 데이터가 아니며 성능이 실제보다 좋게 추정될 수 있다.

## 5. 홀드아웃 검증

홀드아웃은 데이터를 한 번 무작위로 나누어 일부는 학습에, 나머지는 검증에 사용하는 방법이다.

**전체 데이터 → 학습셋과 검증셋 분할 → 학습셋으로 학습 → 검증셋으로 성능 측정**

### 장점

- 구조가 단순하고 계산 비용이 적다.
- 데이터가 충분히 많을 때 빠르게 모델을 비교할 수 있다.

### 한계

- 어떤 표본이 검증셋으로 선택됐는지에 따라 결과가 달라질 수 있다.
- 학습에 사용하는 데이터가 줄어든다.
- 적은 데이터에서는 일부 특이한 표본이 결과에 큰 영향을 줄 수 있다.
- 전체 데이터로 학습한 최종 모델의 오차보다 크게 추정될 수 있다.

## 6. K-fold 교차검증

![[CS/AI/교차검증#핵심 정리]]

K-fold 교차검증은 데이터를 크기가 비슷한 K개 그룹으로 나누고 각 그룹을 한 번씩 검증 데이터로 사용하는 방법이다.

### 처리 과정

1. 전체 데이터를 K개의 fold로 나눈다.
2. 하나의 fold를 검증 데이터로 둔다.
3. 나머지 K-1개 fold로 모델을 학습한다.
4. 검증 fold에서 오차를 계산한다.
5. 검증 fold를 바꾸어 K번 반복한다.
6. K개의 검증 오차를 평균한다.

각 데이터는 검증 데이터로 한 번, 학습 데이터로 K-1번 사용된다.

### 교차검증 오차

각 fold에서 계산한 오차를 $MSE_k$라고 하면 다음과 같이 평균한다.

$$
CV(K)=\frac{1}{K}\sum_{k=1}^{K}MSE_k
$$

분류 문제에서는 MSE 대신 정확도, F1 점수, 로그 손실처럼 문제에 맞는 평가 지표를 사용할 수 있다.

### 장점과 주의점

- 모든 데이터를 학습과 검증에 활용한다.
- 한 번의 홀드아웃보다 분할에 따른 우연한 영향을 줄인다.
- K번의 결과는 서로 완전히 독립적이지 않다.
- 전처리 기준도 각 fold의 학습 데이터에서만 계산해야 한다.
- 교차검증으로 설정을 선택한 뒤에는 선택한 설정으로 전체 학습 데이터를 다시 학습한다.

## 7. LOOCV

LOOCV(Leave-One-Out Cross-Validation)는 데이터가 $n$개일 때 $K=n$으로 설정하는 교차검증이다.

- 학습 데이터: 한 개를 제외한 $n-1$개
- 검증 데이터: 제외한 한 개
- 반복 횟수: $n$번

### 장점

- 매번 거의 전체 데이터로 학습한다.
- 학습 데이터 감소로 발생하는 편향이 작다.
- 데이터를 최대한 학습에 활용한다.

### 한계

- 데이터 개수만큼 모델을 학습하므로 계산 비용이 크다.
- 검증 데이터가 매번 한 개뿐이라 개별 데이터의 영향이 크다.
- 일반적인 K-fold보다 추정 결과의 변동이 커질 수 있다.

## 8. 교차검증 방법 비교

| 방법 | 분할 방법 | 장점 | 한계 |
| --- | --- | --- | --- |
| 홀드아웃 | 한 번 분할 | 빠르고 단순함 | 분할에 따른 변동이 큼 |
| 5-fold CV | 5개 그룹 | 계산량과 안정성의 균형 | 모델을 5번 학습 |
| 10-fold CV | 10개 그룹 | 학습 데이터 비율이 높고 널리 사용 | 5-fold보다 계산량 증가 |
| LOOCV | 데이터 하나씩 검증 | 거의 전체 데이터로 학습 | 계산 비용과 변동성이 큼 |

일반적으로 5-fold 또는 10-fold를 많이 사용한다. K가 클수록 항상 좋은 것은 아니며 데이터 크기, 계산 비용, 모델 학습 시간과 평가 안정성을 함께 고려해야 한다.

## 9. 올바른 모델 선택 흐름

**데이터 분리 → 학습 데이터 안에서 교차검증 → 모델과 하이퍼파라미터 선택 → 전체 학습 데이터로 다시 학습 → 테스트 데이터로 최종 평가**

테스트 데이터는 마지막까지 모델 선택에 사용하지 않는다. 정규화 기준, 결측치 대체값, 특성 선택 기준 같은 전처리도 각 교차검증 반복의 학습 fold에서 계산하고 같은 기준을 검증 fold에 적용해야 한다.

## 10. 반드시 구분할 개념

| 구분 | 핵심 차이 |
| --- | --- |
| 일반화 오차와 테스트 오차 | 테스트 오차는 일반화 오차를 표본으로 추정한 값 |
| 학습 데이터와 검증 데이터 | 파라미터 학습과 모델·설정 선택 |
| 검증 데이터와 테스트 데이터 | 반복적인 선택과 마지막 최종 평가 |
| 홀드아웃과 K-fold | 한 번 분할과 K번 반복 검증 |
| K-fold와 LOOCV | K개 그룹과 데이터 하나씩 검증 |
