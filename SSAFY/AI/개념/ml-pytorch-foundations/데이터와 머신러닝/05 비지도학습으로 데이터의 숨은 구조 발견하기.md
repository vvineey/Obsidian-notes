# 05 비지도학습으로 데이터의 숨은 구조 발견하기

> [!summary] 오늘의 핵심

## 1. 비지도학습

![[CS/AI/비지도학습#핵심 정리]]

비지도학습은 정답인 라벨 없이 데이터 자체에 포함된 구조와 패턴을 발견하는 방법이다. 지도학습처럼 정해진 정답을 예측하는 대신 다음 질문을 다룬다.

- 어떤 데이터끼리 서로 비슷한가?
- 데이터 안에 자연스럽게 구분되는 집단이 있는가?
- 많은 특성을 더 적은 차원으로 표현할 수 있는가?
- 일반적인 패턴에서 크게 벗어난 데이터가 있는가?
- 데이터를 설명하는 잠재적인 표현을 만들 수 있는가?

### 대표적인 비지도학습 작업

| 작업 | 목적 | 예시 |
| --- | --- | --- |
| 클러스터링 | 비슷한 데이터를 같은 집단으로 묶음 | 고객 세분화 |
| 차원 축소 | 많은 특성을 적은 차원으로 표현 | PCA, 시각화 |
| 이상치 탐지 | 일반 패턴에서 벗어난 데이터 탐색 | 비정상 거래 탐지 |
| 표현 학습 | 데이터의 중요한 특징을 새로운 표현으로 변환 | 임베딩 |

비지도학습의 결과는 정답 예측값이 아니라 데이터의 구조나 새로운 표현이다.

## 2. 지도학습과 비지도학습

| 구분 | 지도학습 | 비지도학습 |
| --- | --- | --- |
| 라벨 | 존재함 | 존재하지 않음 |
| 목적 | 입력으로 정답 예측 | 데이터 내부 구조 발견 |
| 대표 작업 | 회귀, 분류 | 군집, 차원 축소, 이상치 탐지 |
| 평가 | 실제 정답과 예측 비교 | 응집도, 분리도, 안정성과 해석 가능성 |
| 결과 | 예측 모델 | 그룹, 구조, 저차원 표현 |

비지도학습도 데이터만 넣으면 객관적인 정답을 자동으로 알려 주는 것은 아니다. 어떤 특성을 사용하고 어떻게 거리를 계산하는지에 따라 전혀 다른 구조가 나타날 수 있다.

## 3. 유사도와 거리

클러스터링은 데이터 사이의 유사성이나 거리를 이용한다. 데이터 사이의 거리가 가까울수록 비슷하다고 판단하는 방식이 일반적이다.

두 데이터 $x$와 $y$의 유클리드 거리는 다음과 같다.

$$
d(x,y)=\sqrt{\sum_{j=1}^{p}(x_j-y_j)^2}
$$

여기서 $p$는 특성의 개수다.

### 거리 기반 분석의 핵심

- 어떤 특성을 선택했는지가 결과를 결정한다.
- 특성의 단위와 범위가 다르면 값이 큰 특성이 거리를 지배할 수 있다.
- 이상치는 중심점과 군집 간 거리에 큰 영향을 줄 수 있다.
- 숫자상 가까운 것이 실제 문제에서도 비슷하다는 보장은 없다.

거리 계산보다 먼저 무엇을 기준으로 유사하다고 볼 것인지 정의해야 한다.

## 4. 클러스터링

![[CS/AI/클러스터링#핵심 정리]]

클러스터링은 라벨이 없는 데이터에서 서로 비슷한 데이터를 같은 군집으로 묶는 방법이다.

좋은 군집은 다음 조건을 만족해야 한다.

- 같은 군집 내부의 데이터는 서로 유사하다.
- 서로 다른 군집의 데이터는 충분히 구분된다.

이를 각각 군집 내 응집도와 군집 간 분리도로 이해할 수 있다.

### 하나의 정답이 없는 이유

같은 데이터라도 사용하는 특성, 스케일링, 거리 함수, 군집 수와 알고리즘에 따라 결과가 달라진다. 수학적으로 나뉘었다는 이유만으로 현실적으로 의미 있는 집단이라고 단정하면 안 된다.

## 5. K-means 클러스터링

K-means는 데이터를 미리 정한 K개의 군집으로 나누는 분할형 클러스터링 알고리즘이다.

각 데이터는 반드시 하나의 군집에 속하고 동시에 여러 군집에 속하지 않으며, 모든 데이터가 K개 군집 중 하나에 포함된다.

### 중심점과 목적 함수

각 군집은 군집에 포함된 데이터의 평균 위치인 중심점, 즉 centroid를 가진다. K-means는 데이터와 해당 군집 중심점 사이의 제곱 거리를 최소화한다.

$$
J=\sum_{k=1}^{K}\sum_{x_i\in C_k}\lVert x_i-\mu_k\rVert^2
$$

- $C_k$: k번째 군집
- $\mu_k$: k번째 군집의 중심점
- $J$: 군집 내부 제곱 거리의 합

$J$가 작을수록 같은 군집의 데이터가 중심점 주변에 가깝게 모여 있다는 뜻이다.

### 알고리즘 진행 과정

1. K개의 초기 중심점을 정하거나 각 데이터를 임시 군집에 할당한다.
2. 각 군집에 속한 데이터의 평균으로 중심점을 계산한다.
3. 각 데이터를 가장 가까운 중심점의 군집으로 다시 할당한다.
4. 새로운 군집을 기준으로 중심점을 다시 계산한다.
5. 군집 할당이나 중심점이 거의 변하지 않을 때까지 반복한다.

### 초기값의 영향

K-means는 초기 중심점에 따라 서로 다른 결과에 도달할 수 있다. 반복 과정은 현재 위치에서 가까운 해를 찾기 때문에 전체적으로 가장 좋은 해를 항상 찾는 것은 아니다. 서로 다른 초기값으로 여러 번 실행하고 목적 함수가 가장 작은 결과를 선택해야 한다.

## 6. 계층적 군집

계층적 군집은 데이터를 나무 형태의 계층 구조로 묶는 방법이다. K-means와 달리 실행 전에 K를 반드시 정하지 않아도 된다.

강의에서는 작은 군집부터 가까운 군집끼리 합치는 병합형 방식인 agglomerative clustering을 다뤘다.

### 병합형 계층적 군집 과정

1. 각 데이터를 하나의 독립된 군집으로 시작한다.
2. 현재 군집 사이의 거리를 계산한다.
3. 가장 가까운 두 군집을 하나로 합친다.
4. 새 군집과 다른 군집의 거리를 계산한다.
5. 모든 데이터가 하나의 군집으로 합쳐질 때까지 반복한다.

### 덴드로그램

덴드로그램은 데이터가 어떤 순서와 거리에서 합쳐졌는지 나타내는 나무 형태의 그림이다.

- 아래쪽 잎: 개별 데이터
- 가지: 데이터 또는 군집의 결합
- 세로축 높이: 두 군집이 결합한 거리
- 높은 위치에서 결합: 서로 다른 성격의 군집
- 낮은 위치에서 결합: 서로 유사한 군집

덴드로그램의 특정 높이를 가로로 잘라 군집 수를 결정한다. 자르는 높이에 따라 군집 수가 달라지므로 해석 목적과 데이터 구조를 함께 고려해야 한다.

## 7. 연결 방법에 따른 차이

계층적 군집에서는 군집과 군집 사이의 거리를 정하는 기준이 필요하다. 이를 linkage라고 한다.

| 연결 방법 | 군집 간 거리 | 특징 |
| --- | --- | --- |
| Single linkage | 가장 가까운 데이터 쌍의 거리 | 사슬 형태가 생기기 쉬움 |
| Complete linkage | 가장 먼 데이터 쌍의 거리 | 조밀하고 분리된 군집을 만드는 경향 |
| Average linkage | 모든 데이터 쌍 거리의 평균 | Single과 Complete의 중간적인 특성 |

같은 데이터라도 linkage에 따라 덴드로그램과 최종 군집 결과가 달라질 수 있다.

## 8. 클러스터링 전 전처리

### 스케일링

클러스터링은 거리를 사용하므로 특성의 단위가 중요하다. 값의 범위가 큰 특성이 거리를 지배하지 않도록 표준화나 정규화로 범위를 맞추는 경우가 많다.

### 이상치

K-means의 중심점은 평균이므로 이상치에 민감하다. 이상치가 중심점을 끌어가거나 이상치만을 위한 군집을 만들 수 있다. 계층적 군집에서도 이상치는 높은 거리에서 별도의 가지로 결합될 수 있다.

### 특성 선택

클러스터링에 넣은 모든 특성이 유사성 판단에 사용된다. 군집 목적과 관련된 특성인지, 단위가 적절한지, 결측치와 이상치가 있는지, 특정 특성이 거리를 지나치게 지배하지 않는지 확인해야 한다.

## 9. 클러스터링 결과 해석

비지도학습에는 미리 정해진 라벨이 없으므로 분류 정확도처럼 정답과 직접 비교하기 어렵다.

- 군집 내부 데이터가 충분히 유사한가?
- 서로 다른 군집이 충분히 분리됐는가?
- 초기값이나 데이터 일부가 바뀌어도 비슷한 결과가 나오는가?
- 각 군집이 현실 문제에서 설명 가능한 특징을 가지는가?
- 특정 군집이 지나치게 작거나 이상치만 포함하지 않는가?

군집 번호 자체에는 순서나 의미가 없다. `군집 0`, `군집 1`은 식별자일 뿐이며 실제 의미는 각 군집의 특성을 분석한 뒤 부여해야 한다.

## 10. 반드시 구분할 개념

| 구분 | 핵심 차이 |
| --- | --- |
| 지도학습과 비지도학습 | 라벨을 이용한 예측과 라벨 없이 구조 탐색 |
| 분류와 클러스터링 | 기존 범주 예측과 새로운 그룹 발견 |
| K-means와 계층적 군집 | K를 먼저 정하는 분할 방식과 계층 구조 생성 |
| 중심점과 실제 데이터 | 중심점은 군집 평균이며 실제 데이터일 필요가 없음 |
| Single과 Complete linkage | 가장 가까운 쌍과 가장 먼 쌍을 군집 거리로 사용 |
| 거리와 현실적 유사성 | 수학적으로 가까운 것과 문제상 비슷한 것은 다를 수 있음 |
| 군집 번호와 군집 의미 | 번호는 식별자일 뿐 의미나 순서를 나타내지 않음 |
