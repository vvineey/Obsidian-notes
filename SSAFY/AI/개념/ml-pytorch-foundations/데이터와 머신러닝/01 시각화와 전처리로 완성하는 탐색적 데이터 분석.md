## 1. 데이터에 맞는 시각화 선택

![[CS/AI/데이터 시각화#핵심 정리]]

표의 숫자만으로는 값의 차이, 분포, 추세와 이상치를 빠르게 파악하기 어렵다. 시각화는 결과를 꾸미는 작업이 아니라 데이터를 이해하고 전처리 방향을 결정하는 분석 과정이다.

| 확인하려는 내용 | 적합한 차트 | 대표 문법 |
| --- | --- | --- |
| 범주별 크기 비교 | 막대그래프 | `bar()` |
| 시간에 따른 변화 | 꺾은선그래프 | `plot()` |
| 두 변수의 관계 | 산점도 | `scatter()` |
| 값의 분포와 빈도 | 히스토그램 | `hist()` |
| 중앙값·사분위수·이상치 | 박스플롯 | `boxplot()` |
| 변수 간 상관관계 | 히트맵 | `heatmap()` |

차트를 먼저 정하고 데이터를 끼워 맞추는 것이 아니라 분석 질문에 따라 차트를 선택해야 한다.

## 2. Matplotlib으로 차트 구성하기

Matplotlib에서 전체 그림은 `Figure`, 그림 안의 개별 그래프 영역은 `Axes`다. `plt.subplots(2, 2)`는 2행 2열의 Axes를 만들며 `axes[행, 열]`로 각 영역에 접근한다.

### 반드시 알아야 할 문법

| 문법·개념                            | 언제 쓰는가         | 동작·반환값             | 주의점                                  |
| -------------------------------- | -------------- | ------------------ | ------------------------------------ |
| `plt.figure(figsize=(w, h))`     | 그림 크기를 정할 때    | 새 Figure 생성        | 단위는 inch다.                           |
| `plt.subplots(r, c)`             | 여러 차트를 배치할 때   | `(fig, axes)` 반환   | Axes 메서드는 `set_title`처럼 `set_`이 붙는다. |
| `bar`, `plot`, `hist`, `scatter` | 비교·추세·분포·관계 표현 | 현재 또는 지정한 Axes에 그림 | 데이터 의미에 맞는 차트를 선택한다.                 |
| `title`, `xlabel`, `ylabel`      | 제목과 축 의미 표시    | 그래프 설명 추가          | 단위가 있다면 축 이름에 함께 적는다.                |
| `legend()`                       | 여러 계열을 구분할 때   | 범례 표시              | 각 계열에 `label`이 있어야 한다.               |
| `xticks(rotation=45)`            | 축 글자가 겹칠 때     | 눈금 글자 회전           | 긴 범주명에 유용하다.                         |
| `tight_layout()`                 | 그래프 요소가 겹칠 때   | 여백 자동 조정           | 모든 요소를 배치한 뒤 호출한다.                   |

운영체제에 따라 한글 폰트를 지정해야 한다. Windows는 `Malgun Gothic`, macOS는 `AppleGothic`, Linux·Colab은 `NanumGothic`을 사용하며 `plt.rcParams["axes.unicode_minus"] = False`로 음수 부호 깨짐을 막는다.

## 3. Seaborn으로 통계 시각화하기

Seaborn은 Matplotlib 기반의 통계 시각화 라이브러리다. DataFrame과 컬럼 이름을 직접 받아 범주별 집계와 분포를 짧은 코드로 표현한다.

| 함수 | 확인하는 내용 | 핵심 구분 |
| --- | --- | --- |
| `countplot` | 범주별 데이터 개수 | y축을 지정하지 않는다. |
| `barplot` | 범주별 수치 데이터의 평균 | `plt.bar`와 달리 평균을 내부에서 계산한다. |
| `boxplot` | 중앙값, 사분위수, 분포와 이상치 | 범주별 분포 비교에 적합하다. |
| `heatmap` | 상관계수와 같은 행렬 | `annot=True`로 값을 표시한다. |
| `histplot` | 연속형 값의 분포 | `kde=True`로 밀도 곡선을 함께 볼 수 있다. |
| `scatterplot` | 두 변수의 관계 | `hue`로 그룹을 나눌 수 있다. |
| `pairplot` | 여러 변수의 분포와 쌍별 관계 | 결측치가 있으면 필요한 컬럼을 정리한다. |

`df.corr(numeric_only=True)`는 수치형 컬럼 사이의 상관계수를 -1부터 1 사이 값으로 계산한다. 1에 가까우면 함께 증가하고 -1에 가까우면 반대로 움직이는 선형 경향이 강하다. 상관관계는 인과관계를 의미하지 않는다.

## 4. 결측치와 이상치 전처리

![[CS/AI/EDA와 데이터 전처리#핵심 정리]]

전처리는 분석과 모델링에 사용할 수 있도록 데이터를 정리하고 변환하는 과정이다. 원본은 바로 바꾸지 않고 `df.copy()`로 사본을 만든 뒤 작업한다.

### 결측치 확인과 대체

| 문법 | 역할 | 주의점 |
| --- | --- | --- |
| `df.isnull().sum()` | 컬럼별 결측치 개수 | 개수와 함께 비율도 확인한다. |
| `df.isnull().mean() * 100` | 컬럼별 결측치 비율 | 결측량의 심각도를 비교할 수 있다. |
| `fillna(값)` | 결측치를 지정한 값으로 대체 | 결과를 다시 할당해야 원본 컬럼에 반영된다. |
| `dropna()` | 결측 행 또는 열 제거 | 데이터 손실을 먼저 고려한다. |
| `mode()[0]` | 첫 번째 최빈값 추출 | `mode()`는 Series를 반환한다. |

- 수치형 데이터는 평균이나 중앙값을 고려한다.
- 분포가 치우치거나 이상치가 크면 평균보다 중앙값이 안정적이다.
- 범주형 데이터는 최빈값을 사용할 수 있다.
- 그룹별 특성이 다르면 전체 평균보다 그룹별 평균이 정보 손실을 줄일 수 있다.

### IQR을 이용한 이상치 처리

`Q1 = quantile(0.25)`, `Q3 = quantile(0.75)`, `IQR = Q3 - Q1`로 계산한다. 일반적으로 `Q3 + 1.5 × IQR`보다 큰 값과 `Q1 - 1.5 × IQR`보다 작은 값을 이상치 후보로 본다.

`clip(upper=상한)`은 상한보다 큰 값을 상한값으로 제한한다. 수량을 보정했다면 `매출 = 단가 × 수량`처럼 그 값으로 만든 파생 컬럼도 다시 계산해야 한다.

## 5. 데이터 변환과 구간화

### 정규화와 인코딩

Min-Max 정규화는 `(값 - 최솟값) / (최댓값 - 최솟값)`으로 값을 0부터 1 사이로 변환한다. 값의 단위와 범위가 크게 다른 컬럼을 함께 다룰 때 사용한다.

문자 범주는 `map()`으로 숫자와 직접 대응시키거나 `astype("category").cat.codes`로 코드화할 수 있다. 단순한 번호는 크기나 순서를 뜻하지 않을 수 있으므로 의미를 구분해야 한다.

### 반드시 알아야 할 문법

| 문법·개념 | 언제 쓰는가 | 동작·반환값 | 주의점 |
| --- | --- | --- | --- |
| `drop(..., axis=1)` | 필요 없는 컬럼 삭제 | 삭제된 새 DataFrame 반환 | 기본적으로 원본을 바꾸지 않으므로 다시 할당한다. |
| `Series.apply(func)` | 각 값에 같은 함수 적용 | 변환된 Series 반환 | `apply(grade)`처럼 함수 자체를 넘긴다. |
| `pd.cut(col, n)` | 값의 폭이 같은 구간 생성 | Interval 범주의 Series | 구간별 데이터 수는 다를 수 있다. |
| `pd.qcut(col, n)` | 데이터 수가 비슷한 구간 생성 | 분위수 기반 범주의 Series | 같은 값이 많으면 구간 경계가 겹칠 수 있다. |
| `cat.add_categories(value)` | category에 새 범주 추가 | 범주가 추가된 Series | 등록되지 않은 값은 바로 `fillna`할 수 없다. |

## 6. 탐색적 데이터 분석

EDA는 데이터를 수정하기 전에 구조, 분포, 문제점과 변수 관계를 파악하는 과정이다. 전처리는 EDA에서 발견한 문제를 실제로 수정하는 과정이다.

### 기본 흐름

분석 목적 설정 → 데이터 구조 확인 → 결측치·이상치 탐색 → 분포와 관계 시각화 → 그룹별 집계 → 전처리 → 특성 생성

### 구조 확인 문법

| 문법 | 확인하는 내용 |
| --- | --- |
| `head()`, `tail()` | 데이터 앞부분과 뒷부분 |
| `shape` | 행과 열 개수 |
| `columns` | 컬럼 목록 |
| `info()` | 자료형과 결측 상태 |
| `describe()` | 수치형 기술통계 |
| `describe(include="object")` | 문자열 범주의 빈도 정보 |
| `value_counts()` | 범주별 개수 |
| `value_counts(normalize=True)` | 범주별 비율 |

### 분석 질문을 집계로 바꾸기

`survived`처럼 0과 1로 구성된 컬럼은 `sum()`이 1의 개수, `mean()`이 1의 비율이 된다. 따라서 Titanic 데이터에서 생존 여부의 합계는 생존자 수, 평균은 생존율이다.

| 분석 목적 | 핵심 문법 |
| --- | --- |
| 그룹별 생존자 수와 생존율 | `groupby(...)["survived"].agg(["sum", "mean"])` |
| 두 기준으로 그룹화 | `groupby(["who", "pclass"])` |
| MultiIndex를 일반 컬럼으로 변환 | `reset_index()` |
| 생존율 순위 정렬 | `sort_values(..., ascending=False)` |
| 성별 × 등급 교차 집계 | `pivot_table()` |
| 상위 10% 경계 계산 | `quantile(0.9)` |
| 조건에 맞는 행과 열 선택 | `loc[조건, 컬럼]` |

## 7. Titanic 데이터 분석과 특성 공학

Titanic 데이터는 891행 15열이며 `survived`는 0이 사망, 1이 생존을 뜻한다.

### 결측치 처리

| 컬럼         | 결측치 | 처리 방법                  |
| ---------- | --: | ---------------------- |
| `embarked` |   2 | 최빈값으로 대체               |
| `age`      | 177 | 성별 평균 나이로 대체           |
| `deck`     | 688 | `No Data` 범주를 추가한 뒤 대체 |

나이를 전체 평균이 아니라 성별 평균으로 채우면 그룹별 나이 분포 차이를 반영할 수 있다. `deck`은 category 자료형이므로 `cat.add_categories("No Data")`를 먼저 적용한 뒤 결측치를 채운다.

### 중복 정보 제거

- `class`는 `pclass`와 같은 등급 정보다.
- `embark_town`은 `embarked`와 같은 승선지 정보다.
- `alive`는 `survived`와 같은 생존 정보다.

분석 목적에 따라 중복 컬럼을 제거해 같은 정보가 반복되는 것을 막는다.

### 특성 공학

- `family = sibsp + parch`: 함께 탑승한 가족 수
- `gender`: 성별을 0과 1로 변환
- `fare_bin`: 요금을 동일 빈도의 5개 구간으로 분류
- `age_bin`: 나이를 동일 폭의 10개 구간으로 분류

특성 공학은 컬럼 수를 늘리는 것이 목적이 아니라 기존 데이터에서 분석 질문에 더 직접적으로 대응하는 정보를 만드는 과정이다. 그룹별 생존율이나 상관관계는 관찰된 관계이므로 그 자체를 생존의 원인이라고 단정해서는 안 된다.
