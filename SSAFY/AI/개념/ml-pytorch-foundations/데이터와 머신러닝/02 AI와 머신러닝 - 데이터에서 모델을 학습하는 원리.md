## 1. AI, ML, DL의 관계

### 인공지능

인공지능(Artificial Intelligence, AI)은 주어진 환경이나 데이터를 인식하고, 추론·예측·행동 선택·계획을 수행하여 목표를 달성하도록 만든 시스템 전체를 뜻한다.

AI는 하나의 특정 알고리즘 이름이 아니다. 목표를 달성하기 위해 규칙을 적용하거나, 가능한 행동을 탐색하거나, 데이터에서 패턴을 학습하는 여러 접근법을 포괄하는 상위 개념이다.

### 머신러닝

머신러닝(Machine Learning, ML)은 AI를 구현하는 여러 방법 중 **데이터로부터 규칙과 패턴을 학습하는 접근법**이다.

사람이 모든 상황의 규칙을 일일이 작성하는 대신 입력과 결과의 예시를 제공하면, 모델이 두 값 사이의 관계를 함수 형태로 추정한다. 학습한 관계는 새로운 데이터의 결과를 예측하거나 분류하는 데 사용된다.

### 딥러닝

딥러닝(Deep Learning, DL)은 머신러닝 안에서 여러 층으로 구성된 신경망을 사용하는 방법이다. 이미지, 음성, 자연어처럼 복잡하고 비정형적인 데이터에서 널리 사용된다.

따라서 포함 관계는 다음과 같다.
![[Pasted image 20260805161748.png|207]]

> **AI ⊃ ML ⊃ DL**

| 구분 | 핵심 의미 | 대표 예시 |
| --- | --- | --- |
| AI | 목표 달성을 위한 지능적 시스템 전체 | 전문가 시스템, 경로 탐색, 추천 시스템 |
| ML | 데이터에서 규칙을 학습하는 AI 방법 | 스팸 분류, 수입 예측, 추천 |
| DL | 신경망을 사용하는 ML의 하위 분야 | 이미지 분류, 음성 인식, 생성 모델 |

### AI가 반드시 ML인 것은 아니다

사람이 조건과 행동을 직접 작성한 규칙 기반 시스템과 휴리스틱 탐색도 AI에 포함될 수 있다. 그러나 이런 시스템이 데이터에서 규칙을 학습하지 않는다면 머신러닝은 아니다.

- 규칙 기반 AI: 사람이 `if-then` 형태의 규칙을 직접 정의한다.
- 머신러닝: 데이터의 입력과 결과를 관찰하여 규칙을 추정한다.

두 방식의 핵심 차이는 **규칙의 출처**다.

## 2. 머신러닝의 기본 구조

머신러닝은 한 번에 완성된 규칙을 얻는 작업이 아니다. 다음 과정을 반복하여 모델의 성능을 개선한다.

**데이터 → 모델 → 학습 → 평가 → 개선 → 재학습**
![[Pasted image 20260805144902.png|514]]

| 단계  | 역할                            |
| --- | ----------------------------- |
| 데이터 | 모델이 관계를 발견할 근거를 제공한다.         |
| 모델  | 입력을 출력으로 변환하는 함수다.            |
| 학습  | 모델의 파라미터를 조정해 예측 오차를 줄인다.     |
| 평가  | 학습한 모델이 목표를 얼마나 잘 달성하는지 확인한다. |

평가 결과가 충분하지 않다면 다음 항목을 다시 살펴봐야 한다.

- 데이터의 양과 품질이 충분한가?
- 문제 해결에 필요한 특성이 포함되어 있는가?
- 잘못된 값이나 편향된 데이터가 섞여 있지 않은가?
- 문제에 알맞은 모델과 가설 공간을 선택했는가?
- 학습 방법과 평가 기준이 적절한가?

따라서 모델의 성능은 알고리즘 하나만으로 결정되지 않는다. 데이터, 문제 정의, 모델, 학습 방법, 평가 방법이 모두 연결되어 있다.

## 3. 특성과 라벨

머신러닝 데이터는 크게 특성(Feature)과 라벨(Label)로 나눌 수 있다.

### 특성

특성은 모델이 예측과 판단에 사용하는 입력 정보다. 일반적으로 `X`로 표현한다.

특성은 반드시 수치형 원본일 필요가 없다. 다음과 같은 다양한 정보가 특성이 될 수 있다.

- 수치: 나이, 가격, 교육 연수, 조회 수
- 범주: 직업, 지역, 상품 종류
- 텍스트: 메일 제목, 리뷰, 문서 내용
- 이미지: 픽셀값이나 이미지에서 추출한 표현
- 음성: 파형이나 주파수 특성

비수치 데이터는 모델이 계산할 수 있는 수치 표현으로 변환한 뒤 사용한다.

### 라벨

라벨은 모델이 맞히려는 정답 또는 학습 목표다. 일반적으로 `Y`로 표현한다.

- 분류 문제: 스팸/정상, 고양이/강아지처럼 카테고리를 예측한다.
- 회귀 문제: 수입, 가격, 온도처럼 연속적인 수치를 예측한다.

### 실생활 예시

#### 유튜브 추천

- 특성: 영상 장르, 크리에이터, 조회 수, 좋아요 수, 사용자의 시청 이력과 구독 채널
- 라벨: 영상 시청 여부, 클릭 여부, 좋아요 여부 등 사용자의 반응

모델은 과거의 사용자 반응을 바탕으로 새로운 영상에 반응할 가능성을 예측한다.

#### 스팸 메일 분류

- 특성: 메일 제목, 발신자, 본문에 등장한 단어와 빈도
- 라벨: 스팸 또는 정상

모델은 특성에 나타난 패턴과 라벨 사이 관계를 학습한 뒤 새로운 메일을 분류한다.

### 문제 정의의 중요성

현실 문제를 머신러닝으로 해결하려면 먼저 무엇을 입력으로 사용할지, 무엇을 예측할지 결정해야 한다.

> 현실의 관찰 정보 → 특성 `X`로 표현 → 목표를 라벨 `Y`로 정의 → `X → Y` 관계 학습

특성이 목표를 설명하는 정보를 충분히 담지 못하거나 라벨이 실제 목표와 다르게 정의되면, 모델은 원하는 문제를 학습할 수 없다.

## 4. 단일 특성 기반 학습

특성이 하나인 학습을 단일 특성 또는 1차원 특성 기반 학습이라고 한다.
교육 연수 하나로 수입을 설명하는 문제는 다음과 같이 표현할 수 있다.

$$
Income_i = f^*(YearsOfEducation_i) + \epsilon_i
$$

| 기호                   | 의미                         |
| -------------------- | -------------------------- |
| $YearsOfEducation_i$ | $i$번째 사람의 교육 연수, 즉 특성      |
| $Income_i$           | $i$번째 사람의 수입, 즉 라벨         |
| $f^*$                | 현실에서 입력과 출력을 연결하는 미지의 참 함수 |
| $\epsilon_i$         | 측정 오차와 관찰되지 않은 요인의 영향      |

### 데이터셋의 표현

관측한 데이터셋은 다음과 같이 특성과 라벨의 쌍으로 표현한다.

$$
D = \{(x_i, y_i)\}_{i=1}^{n}
$$

교육 연수와 수입을 조사했다면 각 데이터는 `(교육 연수, 수입)` 쌍이다. 그래프에서는 각각의 관측값이 점 하나로 표시된다.

### 참 함수와 관측 데이터

참 함수 $f^*$는 특성과 라벨 사이의 실제 평균 관계를 뜻하지만 직접 관찰할 수 없다. 우리가 볼 수 있는 것은 오차가 섞인 데이터뿐이다.

- 참 함수: 현실의 평균적인 관계
- 관측 데이터: 참 함수의 값에 오차가 더해진 결과

따라서 학습의 목적은 관측된 점을 이용하여 참 함수에 가까운 후보 함수 $f$를 찾는 것이다.

### 오차는 완전히 제거할 수 없다

$\epsilon$에는 측정 기기의 한계, 환경적 요인, 조사하지 않은 변수, 우연한 변동 등이 포함될 수 있다.

모델은 데이터에 반복적으로 나타나는 체계적인 관계를 학습할 수 있지만, 우연한 잡음이나 측정 오차를 모두 제거할 수는 없다. 학습을 잘한다는 것은 모든 관측점을 완벽히 통과하는 것이 아니라, 새로운 데이터에도 적용할 수 있는 일반적인 관계를 찾는 것이다.

## 5. 가설 공간과 모델

### 가설 공간

가설 공간(Hypothesis Space) $\mathcal{F}$는 특성과 라벨의 관계를 표현할 수 있는 **모든 후보 함수의 집합**이다.
![[Pasted image 20260805145026.png|375]]

예를 들어 선형 관계만 허용한다면 가설 공간은 다음 형태의 모든 직선으로 구성된다.

$$
y = ax + b
$$

$a$와 $b$의 값에 따라 서로 다른 직선이 만들어지며, 각각이 하나의 후보 함수다.

비선형 가설 공간을 사용하면 직선뿐 아니라 곡선과 더 복잡한 함수도 후보가 될 수 있다.

### 모델

모델 $f$는 가설 공간에 속한 후보 함수 중 실제로 선택된 하나의 함수다.
![[Pasted image 20260805145056.png|549]]

- 가설 공간: 선택할 수 있는 후보 전체
- 모델: 후보 전체 중 선택된 하나

가설 공간과 모델을 같은 의미로 사용하면 안 된다. 가설 공간은 가능성의 범위를 정하고, 학습은 그 범위 안에서 하나의 모델을 찾는다.

### 가설 공간의 복잡도

복잡한 가설 공간이 항상 좋은 것은 아니다.

- 너무 단순한 공간: 실제 관계를 충분히 표현하지 못해 과소적합될 수 있다.
- 너무 복잡한 공간: 학습 데이터의 잡음까지 외워 과적합될 수 있다.

모델은 학습 데이터에 잘 맞으면서도 새로운 데이터에서 성능을 유지해야 한다.

## 6. 학습이란 무엇인가

학습은 주어진 데이터에서 정답을 잘 맞히도록 모델의 규칙 또는 파라미터를 조정하는 과정이다.

개념적으로 다음과 같이 표현할 수 있다.

> 데이터 $D$ → 가설 공간 $\mathcal{F}$ → 선택된 모델 $f$

### 학습에 필요한 세 가지

| 구성 요소 | 역할 |
| --- | --- |
| 데이터 $D$ | 입력과 정답의 예시를 제공한다. |
| 가설 공간 $\mathcal{F}$ | 선택 가능한 후보 함수의 범위를 정한다. |
| 손실 함수 $L$ | 예측값과 실제값의 차이를 수치로 측정한다. |

### 손실 함수

손실 함수는 어떤 후보 모델이 더 좋은지를 판단하는 기준이다. 예측값과 실제값의 차이가 크면 손실이 커지고, 차이가 작으면 손실이 작아진다.

회귀 문제에서는 예측값과 실제값의 차이를 제곱하여 평균한 평균제곱오차를 사용할 수 있다.

$$
MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2
$$

### 학습 과정

1. 가설 공간에서 후보 모델을 선택한다.
2. 모델로 데이터의 라벨을 예측한다.
3. 손실 함수로 예측이 얼마나 틀렸는지 계산한다.
4. 손실이 작아지는 방향으로 모델 파라미터를 조정한다.
5. 이 과정을 반복해 적절한 모델을 얻는다.

### 학습 오차와 일반화

학습 데이터의 오차가 가장 작은 모델이 항상 새로운 데이터에서도 가장 좋은 것은 아니다. 모델이 학습 데이터의 잡음까지 외웠다면 처음 보는 데이터에서 성능이 낮아질 수 있다.

따라서 실제 모델링에서는 학습에 사용하지 않은 검증 데이터나 테스트 데이터로 일반화 성능을 확인해야 한다.

## 7. 여러 특성을 사용하는 모델

현실의 결과는 하나의 특성만으로 결정되지 않는 경우가 많다. 수입을 예측할 때 교육 연수뿐 아니라 근속 연수도 사용할 수 있다.

$$
Income = f^*(YearsOfEducation, Seniority) + \epsilon
$$

특성이 두 개이면 입력 공간은 2차원이 되고, 하나의 수치 라벨을 예측하는 함수는 3차원 그래프에서 평면이나 곡면으로 표현할 수 있다.

### 일반적인 다중 특성 표현

특성이 $p$개라면 하나의 입력 벡터로 묶는다.

$$
X =
\begin{bmatrix}
X_1 \\
X_2 \\
\vdots \\
X_p
\end{bmatrix}
\in \mathbb{R}^p
$$

모델은 다음과 같이 표현한다.

$$
Y = f^*(X) + \epsilon, \qquad f^*: \mathbb{R}^p \rightarrow \mathbb{R}
$$

- $X$: 여러 특성을 모은 입력 벡터
- $Y$: 예측하려는 라벨
- $f^*$: 입력 벡터를 라벨로 연결하는 참 함수
- $\epsilon$: 모델이 설명하지 못하는 오차

### 강의에서 사용하는 오차 가정

강의에서는 수학적 설명을 위해 다음을 기본적으로 가정한다.

- 오차 $\epsilon$은 특성 $X$와 독립이다.
- 오차의 평균은 0이다: $E[\epsilon] = 0$

이는 관계를 단순하게 분석하기 위한 이상적인 가정이다. 실제 데이터에서는 오차의 크기가 입력에 따라 달라지거나 특정 특성과 관련될 수 있으므로 가정이 적절한지 별도로 확인해야 한다.

## 8. 모델을 학습하는 이유

### 예측

잘 학습된 모델이 있으면 새로운 입력 $x$가 주어졌을 때 목표값 $Y$를 예측할 수 있다.

예를 들어 교육 연수와 근속 연수가 주어졌을 때 예상 수입을 계산하거나, 새로운 메일이 스팸인지 분류할 수 있다.

### 중요 특성 파악

여러 특성 중 어떤 특성이 결과를 설명하는 데 더 중요하고 어떤 특성이 덜 관련되어 있는지 확인할 수 있다.

수입 예측 문제에서는 교육 연수와 근속 연수가 큰 관련을 보이지만, 혼인 여부는 상대적으로 관련이 작을 수 있다.

### 해석

모델의 형태와 복잡도에 따라 각 특성이 결과에 어떤 영향을 미치는지 분석할 수 있다.

- 특성이 증가할 때 예측값이 증가하는가, 감소하는가?
- 변화의 크기는 어느 정도인가?
- 특정 범위에서 영향이 더 크게 나타나는가?

단, 복잡한 모델은 정확도가 높더라도 내부 판단을 직접 해석하기 어려울 수 있다.

### 중요도와 인과관계는 다르다

모델이 특정 특성을 중요하게 사용했다는 사실은 그 특성과 결과 사이에 통계적인 관련성이 있다는 뜻이다. 그 특성이 결과의 원인이라는 뜻은 아니다.

인과관계를 주장하려면 실험, 통제, 시간적 선후 관계 확인 등 별도의 연구 설계와 검증이 필요하다.

| AI와 ML | ML은 AI의 하위 분야이며 모든 AI가 ML은 아니다. |
| ML과 DL | DL은 신경망을 사용하는 ML의 하위 분야다. |
| 특성과 라벨 | 특성은 입력, 라벨은 예측 목표다. |

| 가설 공간과 모델 | 가설 공간은 후보 전체, 모델은 선택된 하나다. |
