# 00 자연어처리 기본 인덱스

> [!summary]
> 자연어를 토큰과 벡터로 표현하는 단계부터 순환 모델, Attention, Transformer와 사전학습 언어 모델까지 이어지는 흐름을 네 개 대단원으로 정리한다. 각 노트는 2026-08-20 AI 이론 평가의 정의·원리·비교·한계 중심으로 구성한다.

- 텍스트가 token ID와 embedding을 거쳐 문맥 표현으로 변환되는 흐름을 설명한다.
- RNN/LSTM, Seq2Seq/Attention, Transformer의 문제 해결 관계를 연결한다.
- 사전학습 모델 구조별 문맥 방향과 학습 목표를 비교한다.

## 3. 전체 정보 흐름

```text
텍스트
  → 토큰화와 token ID
  → 임베딩
  → RNN/LSTM의 순차 문맥
  → Seq2Seq의 입력 조건부 생성
  → Attention의 동적 입력 참조
  → Self-Attention과 Transformer
  → 대규모 자기지도 사전학습
  → Fine-tuning 또는 In-Context Learning
```

## 4. 0820 평가 체크리스트

- [ ] One-hot, embedding, token ID를 구분한다.
- [ ] RNN의 hidden state와 LSTM의 cell state를 구분한다.
- [ ] LSTM의 세 gate를 설명한다.
- [ ] Seq2Seq encoder와 decoder의 역할을 설명한다.
- [ ] Attention의 `score → softmax → weighted sum`을 설명한다.
- [ ] Q, K, V와 scaling의 목적을 설명한다.
- [ ] positional encoding, padding mask, causal mask를 구분한다.
- [ ] attention, FFN, residual connection, LayerNorm의 역할을 구분한다.
- [ ] Encoder-only, Decoder-only, Encoder–Decoder를 비교한다.
- [ ] Fine-tuning과 In-Context Learning의 파라미터 변경 여부를 구분한다.
