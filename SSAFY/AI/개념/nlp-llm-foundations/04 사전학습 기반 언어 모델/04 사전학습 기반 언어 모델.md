# 04 사전학습 기반 언어 모델

> [!summary] 오늘의 핵심
> 사전학습 언어 모델은 대규모 말뭉치에서 토큰 예측 같은 자기지도 목표를 먼저 학습하여 일반적인 언어 표현과 생성 능력을 얻는다. Encoder-only는 양방향 문맥 이해, Decoder-only는 causal next-token prediction, Encoder–Decoder는 입력 조건부 생성에 강점이 있다. 이후 fine-tuning, prompting, in-context learning으로 과업에 적응한다.

## 학습 목표

- 사전학습과 downstream 적응을 구분한다.
- Encoder-only, Decoder-only, Encoder–Decoder의 attention 범위와 학습 목표를 비교한다.
- Fine-tuning과 In-Context Learning에서 파라미터가 변하는지 설명한다.
- Zero-shot, Few-shot, CoT의 목적과 한계를 비교한다.

## 1. 사전학습이란

작은 과업 데이터만으로 큰 모델을 처음부터 학습하면 일반적인 언어 규칙과 지식을 충분히 익히기 어렵다. 사전학습은 대규모 텍스트로 범용 표현을 먼저 학습하고, 이를 여러 downstream task에 재사용한다.

```text
대규모 말뭉치 → 자기지도 사전학습 → 범용 언어 모델
                                  ├→ Fine-tuning
                                  ├→ Prompting / ICL
                                  └→ 분류·검색·요약·번역·생성
```

사전학습은 비용이 크지만 한 번 얻은 표현을 여러 문제에 전이할 수 있다. 다만 학습 말뭉치의 편향, 오래된 지식과 오류도 함께 학습될 수 있다.

## 2. 자기지도 학습

자기지도 학습은 사람이 별도 라벨을 붙이지 않고 데이터 자체에서 입력과 정답을 구성한다.

### Masked Language Modeling

일부 토큰을 가리고 주변의 양방향 문맥으로 원래 토큰을 예측한다.

```text
오늘 날씨가 [MASK] → 좋다
```

문장 전체의 좌우 문맥을 활용하는 표현 학습에 적합하다.

### Causal Language Modeling

이전 토큰만 보고 다음 토큰을 예측한다.

$$\mathcal{L}=-\sum_t\log P(x_t\mid x_{<t})$$

학습 목표가 생성 과정과 자연스럽게 일치해 자기회귀 텍스트 생성에 적합하다.

### Denoising / Seq2Seq Objective

입력을 마스킹·삭제·순서 변경 등으로 훼손하고 원래 문장을 복원한다. encoder가 전체 입력을 읽고 decoder가 출력 시퀀스를 생성한다.

## 3. Encoder-only 모델

Encoder-only 모델은 모든 입력 토큰이 좌우 문맥을 볼 수 있는 양방향 self-attention을 사용한다. 대표적으로 BERT 계열이 있다.

- 문장·토큰 분류
- 개체명 인식
- 임베딩과 검색 표현
- 추출형 질의응답

전체 문맥을 이해하는 데 강하지만 기본 구조 자체는 왼쪽부터 긴 문장을 자기회귀 생성하도록 설계된 decoder가 아니다.

## 4. Decoder-only 모델

Decoder-only 모델은 causal mask로 미래 토큰을 가리고 다음 토큰을 예측한다. GPT 계열이 대표적이다.

```text
입력 prompt → causal Transformer blocks → 다음 token logits
      ← 이전 토큰만 참고 가능 →
```

출력층은 hidden state를 vocabulary 크기의 logits로 투영한다. softmax가 확률 분포를 만들고 decoding 정책이 실제 토큰을 고른다. 선택된 토큰을 다시 입력에 붙여 반복한다.

> [!important]
> 모델이 “다음 토큰 예측”만 학습한다고 해서 단순 암기만 하는 것은 아니다. 다양한 문맥에서 다음 토큰을 맞히려면 문법, 의미 관계, 문서 구조와 여러 패턴을 내부 표현에 담아야 한다. 그러나 이것이 사실성이나 논리적 정확성을 보장하지는 않는다.

## 5. Encoder–Decoder 모델

Encoder는 전체 입력을 양방향으로 표현하고 decoder는 causal self-attention과 cross-attention으로 출력을 생성한다. T5, BART 같은 구조가 대표적이다.

| 단계 | 정보 접근 |
|---|---|
| Encoder self-attention | 입력 전체 |
| Decoder self-attention | 지금까지 생성한 출력 |
| Cross-attention | decoder query가 encoder 출력 참조 |

번역, 요약처럼 명시적인 입력을 다른 출력 시퀀스로 변환하는 조건부 생성에 자연스럽다.

## 6. Fine-tuning과 In-Context Learning

| 방식 | 파라미터 변경 | 필요한 것 | 특징 |
|---|---|---|---|
| Full Fine-tuning | 전체 또는 대부분 변경 | 학습 데이터·gradient | 높은 적응력, 큰 비용 |
| PEFT | 일부 추가·선택 파라미터 변경 | 학습 데이터·gradient | 저장·학습 비용 감소 |
| Prompting | 변경 없음 | 지시문 | 빠르지만 표현에 민감 |
| In-Context Learning | 변경 없음 | prompt 안의 설명·예시 | 문맥에서 과업 패턴을 임시 적용 |

In-Context Learning(ICL)은 입력 문맥 안의 지시와 예시를 보고 과업을 수행하는 현상이다. 추론 중 모델 파라미터가 gradient로 갱신되는 학습과는 다르다.

### Zero-shot과 Few-shot

- **Zero-shot**: 예시 없이 지시만 제공한다. 짧고 저렴하지만 모호한 형식에 취약하다.
- **Few-shot**: 소수의 입출력 예시로 패턴, 기준과 출력 형식을 보여준다. 일관성은 높일 수 있지만 context를 더 소비하고 예시 편향을 받을 수 있다.

## 7. 프롬프팅과 생성 제어

좋은 프롬프트는 역할 자체보다 과업, 입력, 제약, 평가 기준과 출력 형식을 명확히 한다.

### Chain-of-Thought

복합 문제를 중간 단계로 분해하도록 유도한다. 추론 성능을 높일 수 있지만 항상 정확하지 않고, 길어진 설명이 정답의 증거가 되는 것도 아니다. 실제 시스템에서는 내부 추론 전체를 요구하기보다 검증 가능한 근거와 간결한 결과를 요청하는 방식이 유용하다.

### 구조화된 출력

JSON Schema 같은 제약은 후처리 가능한 형식을 안정화한다. 그러나 **형식 준수와 내용의 사실성은 별개**다. schema validation, 값 범위 검사와 외부 근거 확인이 추가로 필요하다.

### Temperature

logit을 temperature $\tau$로 나누어 softmax에 넣는다.

$$P_i=\frac{\exp(z_i/\tau)}{\sum_j\exp(z_j/\tau)}$$

- 낮은 temperature: 분포가 뾰족해져 일관성이 커진다.
- 높은 temperature: 분포가 평평해져 다양성이 커지지만 오류 가능성도 커질 수 있다.

## 8. 한계와 평가

- **환각**: 그럴듯하지만 근거 없는 내용을 생성할 수 있다.
- **편향**: 사전학습 데이터와 정렬 과정의 편향을 반영한다.
- **지식 시점**: 학습 이후 정보나 변동 사실을 자동으로 알지 못한다.
- **Prompt sensitivity**: 표현, 예시 순서와 문맥에 따라 결과가 달라진다.
- **평가 누수**: 평가 문항이 학습 데이터에 포함되면 능력을 과대평가할 수 있다.

LLM as a Judge는 대량 평가에 유용하지만 자기 선호, 위치 편향, 길이 편향이 있다. 명시적 rubric, 답안 순서 교환, 여러 평가자와 사람 검토를 결합해야 한다.

## 9. 평가 대비 핵심

| 구조 | 문맥 방향 | 대표 학습 목표 | 강점 |
|---|---|---|---|
| Encoder-only | 양방향 | Masked LM | 이해·분류·표현 |
| Decoder-only | 단방향 causal | Next-token prediction | 자유 생성·ICL |
| Encoder–Decoder | 입력 양방향 + 출력 causal | Denoising/Seq2Seq | 입력 조건부 생성 |
