## 1. 자연어를 숫자로 바꾸는 과정

모델은 문자열을 직접 계산하지 못한다. 일반적인 입력 흐름은 다음과 같다.

```text
문장 → 토큰화 → token ID → 임베딩 벡터 → 순차 모델 → 출력
```

- **토큰(token)**: 모델이 처리하는 문자열 단위
- **어휘 집합(vocabulary)**: 모델이 구분하는 토큰 목록
- **token ID**: 각 토큰에 부여한 정수 인덱스
- **OOV**: 어휘 집합에 없는 표현

단어 토큰화는 시퀀스가 짧지만 OOV와 거대한 vocabulary 문제가 크다. 문자 토큰화는 OOV가 적지만 시퀀스가 길어진다. 서브워드는 자주 나오는 문자열은 크게, 드문 단어는 작은 단위로 나누어 두 극단을 절충한다.

> [!important] 0820 포인트
> token ID의 숫자 크기에는 의미나 순서가 없다. ID 100이 ID 10보다 의미가 크거나 가깝다는 뜻이 아니다.

## 2. 워드 임베딩

### One-hot 표현의 한계

Vocabulary 크기가 $V$이면 One-hot 벡터의 차원도 $V$다. 단 하나의 원소만 1이므로 희소하고, 서로 다른 두 토큰의 내적은 항상 0이다. 따라서 학습 전에는 단어 사이의 유사성을 표현하지 못한다.
![[Pasted image 20260818170434.png]]


### 워드 임베딩

단어들 단어들 사이의 의미적 관계를 포착할 수 있는 밀집되고 연속적/분산적 벡터 표현으로 나타내는 기법이다.
- One-hot 인코딩에서는 은행과 금융이 완전히 독립적인 벡터로 표현되었지만, 
  워드 임베딩에선 두 단어의 벡터가 공간상 서로 가깝게 위치하며 이를 통해 의미적 유사성을 반영할 수 있다.
![[Pasted image 20260818170750.png|423]]


### Word2Vec

2013년 Google에서 개발한 워드 임베딩 기법이다. 단어의 표현을 간단한 인공 신경망을 이용하여 학습한다.

Word2Vec에는 두 가지 알고리즘이 존재한다.
- Skip-grams (SG) 방식
- Continuous Bag of Words (CBOW) 방식


1. Skip-grams (SG) : 중심 단어를 통해 주변 단어 예측하기
   - window size를 설정하여 중심 단어 주변 몇 개 단어를 문맥으로 볼 것인가 결정

2.  Continuos Bag of Words (CBOW) : 주변 단어를 통해 중심 단어 예측하기
   - 주변 단어들의 집합이 주어졌을 때, 그 문맥과 함께 등장할 수 있는 단일 단어를 예측한다.

### 밀집 임베딩

임베딩 행렬을 $E\in\mathbb{R}^{V\times d}$라고 하면 token ID $i$의 임베딩은 $E$의 $i$번째 행이다.

$$e_i=E[i]\in\mathbb{R}^{d}$$

$d$는 보통 $V$보다 훨씬 작다. 임베딩 값은 손실을 줄이는 방향으로 학습되며, 비슷한 문맥에서 비슷한 역할을 하는 토큰이 가까운 벡터를 갖도록 유도될 수 있다.

| 구분  | One-hot       | 임베딩             |
| --- | ------------- | --------------- |
| 차원  | vocabulary 크기 | 정한 embedding 차원 |
| 형태  | 희소 벡터         | 밀집 실수 벡터        |
| 학습  | 고정 표현         | 보통 학습되는 파라미터    |
| 유사성 | 직접 표현 못 함     | 거리·각도로 비교 가능    |

Cosine similarity는 벡터의 크기보다 방향의 유사성을 측정한다.

$$\cos(e_a,e_b)=\frac{e_a\cdot e_b}{\lVert e_a\rVert\lVert e_b\rVert}$$

> [!warning] 오개념
> 임베딩 차원 하나가 항상 성별, 감정처럼 사람이 이름 붙일 수 있는 의미 하나에 대응하는 것은 아니다. 의미는 여러 차원에 분산되어 표현된다.

## 3. 순차 데이터와 RNN

### 순차적 데이터 

데이터가 입력되는 순서와 이 순서를 통해 입력되는 데이터들 사이의 관계가 중요한 데이터이다.

1. 순서가 중요하다.
   - 데이터의 순서가 바뀌면 의미가 달라진다.

2. 장기 의존성 (Long-term dependency)
   - 멀리 떨어진 과거의 정보가 현재/미래에 영향을 준다.
   
3. 가변 길이 (Variable length)
   - 순차 데이터는 길이가 일정하지 않고, 단어 수도 제각각이다.

따라서 순차적 데이터를 처리하려면 일반적인 모델들 (선형 회귀, MLP 등)로는 불가능하다.
-> **Sequential Models** 필요 ( RNN, LSTM, Transformer)


## 4. RNN의 학습과 한계

전통적인 인공신경망 (MLP, CNN)들은 고정된 길이의 입력을 ㅂ다아 가변 길이의 데이터를 처리하기에 적합하지 않다.
하지만, RNN은 가변 길이의 입력을 받을 수 있고, 이전 입력을 기억할 수 있기 때문에 **순차적 데이터 처리**에 적합한 아키텍쳐이다. 

Bag-of-Words처럼 순서를 버리면 “개가 사람을 물었다”와 “사람이 개를 물었다”를 구분하기 어렵다. RNN은 현재 입력 $x_t$와 이전 은닉 상태 $h_{t-1}$를 함께 사용한다.
따라서 입력 시퀸스 벡터 $x$를 처리할 때, 각 시점마다 recurrence  수식을 적용하여  hidden state를 업데이트한다. 

$$h_t=\tanh(W_{xh}x_t+W_{hh}h_{t-1}+b_h)$$
![[Pasted image 20260818172721.png]]
$$y_t=W_{hy}h_t+b_y$$

```text
x₁ → h₁ → h₂ → h₃
           ↑     ↑
          x₂    x₃
```

같은 가중치를 모든 시점에 공유하므로 길이가 달라도 처리할 수 있다. $h_t$는 시점 $t$까지의 정보를 압축한 문맥 표현이다.

### 입출력 형태

| 형태                  | 사례              |
| ------------------- | --------------- |
| many-to-one         | 문장 감정 분류        |
| one-to-many         | 하나의 조건으로 시퀀스 생성 |
| many-to-many(동일 길이) | 토큰별 품사 태깅       |
| many-to-many(다른 길이) | 번역, 요약          |

- RNN은 한 번에 하나의 요소를 처리하고 정보를 앞으로 전달한다. 
- 펼쳐서 보면  RNN 각 층이 하나의 시점을 나타내는 깊은 신경망처럼 보인다.
- RNN은 hidden state를 유지하면서 가변 길이 데이터를 처리할 수 있다.
- RNN의 출력은 과거 입력에 영향을 받는다는 점에서 feedforward 신경망과 다르다.


RNN은 시간을 펼친 계산 그래프에서 BPTT(Backpropagation Through Time)로 학습한다. 멀리 떨어진 시점으로 gradient가 전달될 때 같은 종류의 행렬 곱과 활성화 함수 미분이 반복된다.

*기울기 소실 (vanishing gradient) 문제

- 딥러닝에서 역전파 시 앞쪽 층의 기울기가 0에 가까워져 장기 의존성 학습이 어려운 현상
- 미분값이 계속 1보다 작게 작용하면 (작은 값들이 계속 곱해지면) **기울기 소실**이 발생한다.
- 계속 크게 증폭되면 **기울기 폭주**가 발생한다.
- 기울기 소실은 앞부분 정보가 뒤의 손실에 미치는 영향을 학습하기 어렵게 한다.
- 따라서 긴 문장에서 멀리 떨어진 단어 사이의 **장기 의존성**을 학습하지 못하고 단기 의존성만 포착하게 된다.

 ![[Pasted image 20260818173044.png]]

> [!note]
> 은닉 상태가 존재한다고 해서 모든 과거 정보가 완벽히 기억되는 것은 아니다. 고정 크기 상태에 정보가 반복해서 섞이고, 학습 신호도 긴 경로를 지나야 한다.

## 5. LSTM

기울기 소실 문제를 해결하기 위해 제안된 RNN의 한 종류이다. 
- 시점 t에서 RNN은 길이가 $n$인 벡터 hidden state $h_t$와  cell state $C_t$를 가진다.
- **Hidden state** : short-term information을 저장한다.
- **Cell state** : long-term informartion을 저장한다.

LSTMs는 Cell state에서 정보를 읽고 지우고 기록할 수 있다.


LSTM은 은닉 상태 $h_t$와 별도로 cell state $c_t$를 둔다. 세 gate는 sigmoid를 사용해 닫힘 (0)과 열림(1) 사이의 값으로 정보 흐름을 조절한다.
게이트는 동적으로 계산되며 현재 입력과 hidden state 등 문맥에 따라 값이 정해진다. 

![[Pasted image 20260818174538.png]]


### Forget gate
$$f_t=\sigma(W_f[x_t,h_{t-1}]+b_f)$$

![[Pasted image 20260818174706.png|568]]


### Input gate
$$i_t=\sigma(W_i[x_t,h_{t-1}]+b_i)$$
$$\tilde{c}_t=\tanh(W_c[x_t,h_{t-1}]+b_c)$$
![[Pasted image 20260818174738.png|586]]



### New cell content
$$c_t=f_t\odot c_{t-1}+i_t\odot\tilde{c}_t$$
![[Pasted image 20260818174826.png|600]]


### Output gate
$$o_t=\sigma(W_o[x_t,h_{t-1}]+b_o)$$
$$h_t=o_t\odot\tanh(c_t)$$
![[Pasted image 20260818174851.png]]

| 구성 요소 | 질문 | 역할 |
|---|---|---|
| Forget gate $f_t$ | 무엇을 버릴까? | 이전 cell state의 보존 비율 결정 |
| Input gate $i_t$ | 무엇을 쓸까? | 새 후보 정보의 반영 비율 결정 |
| Cell state $c_t$ | 무엇을 오래 운반할까? | 장기 정보 경로 |
| Output gate $o_t$ | 무엇을 드러낼까? | 현재 hidden state로 내보낼 정보 결정 |

cell state의 핵심은 이전 상태와 새 정보를 **덧셈 경로**로 갱신한다는 점이다. 이 경로가 기본 RNN보다 gradient를 오래 전달하기 쉽게 만든다. 다만 문제를 완전히 제거하는 것은 아니며 계산량이 늘고 순차 연산으로 병렬화가 어렵다.
