# 01 워드 임베딩과 순환신경망

> [!summary] 오늘의 핵심
> 자연어 모델은 먼저 이산적인 토큰을 밀집 벡터로 바꾸고, RNN은 이전 시점의 은닉 상태를 다음 시점으로 전달해 순서를 반영한다. 기본 RNN은 긴 문맥에서 기울기 소실이 발생하기 쉬우며, LSTM은 별도의 cell state와 세 개의 gate로 정보의 보존·삭제·출력을 조절한다.

## 1. 자연어를 숫자로 바꾸는 과정

모델은 문자열을 직접 계산하지 못한다. 일반적인 입력 흐름은 다음과 같다.

```text
문장 → 토큰화 → token ID → 임베딩 벡터 → 순차 모델 → 출력
```

- **토큰(token)**: 모델이 처리하는 문자열 단위
- **어휘 집합(vocabulary)**: 모델이 구분하는 토큰 목록
- **token ID**: 각 토큰에 부여한 정수 인덱스
- **OOV**: 어휘 집합에 없는 표현

단어 토큰화는 시퀀스가 짧지만 OOV와 거대한 vocabulary 문제가 크다. 문자 토큰화는 OOV가 적지만 시퀀스가 길어진다. 서브워드는 자주 나오는 문자열은 크게, 드문 단어는 작은 단위로 나누어 두 극단을 절충한다.

> [!important] 0820 포인트
> token ID의 숫자 크기에는 의미나 순서가 없다. ID 100이 ID 10보다 의미가 크거나 가깝다는 뜻이 아니다.

## 2. 워드 임베딩

### One-hot 표현의 한계

Vocabulary 크기가 $V$이면 One-hot 벡터의 차원도 $V$다. 단 하나의 원소만 1이므로 희소하고, 서로 다른 두 토큰의 내적은 항상 0이다. 따라서 학습 전에는 단어 사이의 유사성을 표현하지 못한다.

### 밀집 임베딩

임베딩 행렬을 $E\in\mathbb{R}^{V\times d}$라고 하면 token ID $i$의 임베딩은 $E$의 $i$번째 행이다.

$$e_i=E[i]\in\mathbb{R}^{d}$$

$d$는 보통 $V$보다 훨씬 작다. 임베딩 값은 손실을 줄이는 방향으로 학습되며, 비슷한 문맥에서 비슷한 역할을 하는 토큰이 가까운 벡터를 갖도록 유도될 수 있다.

| 구분 | One-hot | 임베딩 |
|---|---|---|
| 차원 | vocabulary 크기 | 정한 embedding 차원 |
| 형태 | 희소 벡터 | 밀집 실수 벡터 |
| 학습 | 고정 표현 | 보통 학습되는 파라미터 |
| 유사성 | 직접 표현 못 함 | 거리·각도로 비교 가능 |

Cosine similarity는 벡터의 크기보다 방향의 유사성을 측정한다.

$$\cos(e_a,e_b)=\frac{e_a\cdot e_b}{\lVert e_a\rVert\lVert e_b\rVert}$$

> [!warning] 오개념
> 임베딩 차원 하나가 항상 성별, 감정처럼 사람이 이름 붙일 수 있는 의미 하나에 대응하는 것은 아니다. 의미는 여러 차원에 분산되어 표현된다.

## 3. 순차 데이터와 RNN

Bag-of-Words처럼 순서를 버리면 “개가 사람을 물었다”와 “사람이 개를 물었다”를 구분하기 어렵다. RNN은 현재 입력 $x_t$와 이전 은닉 상태 $h_{t-1}$를 함께 사용한다.

$$h_t=\tanh(W_{xh}x_t+W_{hh}h_{t-1}+b_h)$$

$$y_t=W_{hy}h_t+b_y$$

```text
x₁ → h₁ → h₂ → h₃
           ↑     ↑
          x₂    x₃
```

같은 가중치를 모든 시점에 공유하므로 길이가 달라도 처리할 수 있다. $h_t$는 시점 $t$까지의 정보를 압축한 문맥 표현이다.

### 입출력 형태

| 형태 | 사례 |
|---|---|
| many-to-one | 문장 감정 분류 |
| one-to-many | 하나의 조건으로 시퀀스 생성 |
| many-to-many(동일 길이) | 토큰별 품사 태깅 |
| many-to-many(다른 길이) | 번역, 요약 |

## 4. RNN의 학습과 한계

RNN은 시간을 펼친 계산 그래프에서 BPTT(Backpropagation Through Time)로 학습한다. 멀리 떨어진 시점으로 gradient가 전달될 때 같은 종류의 행렬 곱과 활성화 함수 미분이 반복된다.

- 미분값이 계속 1보다 작게 작용하면 **기울기 소실**이 발생한다.
- 계속 크게 증폭되면 **기울기 폭주**가 발생한다.
- 기울기 소실은 앞부분 정보가 뒤의 손실에 미치는 영향을 학습하기 어렵게 한다.
- 따라서 긴 문장에서 멀리 떨어진 단어 사이의 **장기 의존성**을 잡기 어렵다.

> [!note]
> 은닉 상태가 존재한다고 해서 모든 과거 정보가 완벽히 기억되는 것은 아니다. 고정 크기 상태에 정보가 반복해서 섞이고, 학습 신호도 긴 경로를 지나야 한다.

## 5. LSTM

LSTM은 은닉 상태 $h_t$와 별도로 cell state $c_t$를 둔다. 세 gate는 sigmoid를 사용해 0과 1 사이의 값으로 정보 흐름을 조절한다.

$$f_t=\sigma(W_f[x_t,h_{t-1}]+b_f)$$
$$i_t=\sigma(W_i[x_t,h_{t-1}]+b_i)$$
$$\tilde{c}_t=\tanh(W_c[x_t,h_{t-1}]+b_c)$$
$$c_t=f_t\odot c_{t-1}+i_t\odot\tilde{c}_t$$
$$o_t=\sigma(W_o[x_t,h_{t-1}]+b_o)$$
$$h_t=o_t\odot\tanh(c_t)$$

| 구성 요소 | 질문 | 역할 |
|---|---|---|
| Forget gate $f_t$ | 무엇을 버릴까? | 이전 cell state의 보존 비율 결정 |
| Input gate $i_t$ | 무엇을 쓸까? | 새 후보 정보의 반영 비율 결정 |
| Cell state $c_t$ | 무엇을 오래 운반할까? | 장기 정보 경로 |
| Output gate $o_t$ | 무엇을 드러낼까? | 현재 hidden state로 내보낼 정보 결정 |

cell state의 핵심은 이전 상태와 새 정보를 **덧셈 경로**로 갱신한다는 점이다. 이 경로가 기본 RNN보다 gradient를 오래 전달하기 쉽게 만든다. 다만 문제를 완전히 제거하는 것은 아니며 계산량이 늘고 순차 연산으로 병렬화가 어렵다.

## 6. RNN과 LSTM 비교

| 구분 | 기본 RNN | LSTM |
|---|---|---|
| 상태 | hidden state | hidden state + cell state |
| 정보 제어 | 단일 갱신식 | 세 gate |
| 장기 의존성 | 취약 | 상대적으로 강함 |
| 파라미터·계산 | 적음 | 많음 |
| 병렬 처리 | 시간축 순차 처리 | 시간축 순차 처리 |

## 7. 평가 대비 핵심

> [!question] 예상 문제
> 1. One-hot보다 임베딩이 효율적인 이유를 희소성·차원·유사성 관점에서 설명하라.
> 2. RNN이 단어 순서를 반영할 수 있는 이유는 무엇인가?
> 3. 기울기 소실과 장기 의존성의 관계를 설명하라.
> 4. LSTM의 세 gate와 cell state 역할을 각각 설명하라.

서술형 답안 구조: **RNN의 문제 → 긴 곱셈 경로에서 gradient 약화 → LSTM의 cell state와 gate → 선택적 보존·삭제로 개선 → 계산량과 순차 처리 한계**.
