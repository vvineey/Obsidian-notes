1. 각 AI 개념을 한 문장으로 정의하고 필요한 이유를 설명한다.
2. 유사 개념 두 가지의 공통점과 차이점을 비교한다.

## 1. 출제 관점과 우선순위

- 결과가 달라지는 이유와 개선 방향

### 1.2 낮은 우선순위 또는 제외

## 5. 챕터를 가로지르는 통합 개념

### 5.1 표현 학습

- 표 feature → MLP hidden representation
- token → embedding → contextual representation
- pixel → CNN feature map 또는 ViT token
- image와 text → CLIP 공동 임베딩

### 5.2 학습 목표 비교

| 학습 목표 | 모델 사례 | 무엇을 학습하는가 |
|---|---|---|
| 회귀 | Linear Regression | 연속값 오차 최소화 |
| 분류 | Logistic Regression, MLP, ResNet | 정답 클래스 확률 증가 |
| 군집화 | KMeans | 군집 내부 거리 최소화 |
| 차원 축소 | PCA | 큰 분산 보존 |
| 언어 생성 | GPT | 다음 토큰 확률 예측 |
| 대조학습 | CLIP | 대응 쌍은 가깝게, 비대응 쌍은 멀게 |
| 이미지 생성 | Diffusion | 노이즈 제거 과정 학습 |
| 지식 증류 | Teacher–Student | 정답과 Teacher 분포를 함께 모방 |

### 5.3 공통적인 일반화 문제

- Train 성능과 실제 성능의 차이
- 데이터 분포 변화와 Domain Shift
- 데이터 불균형과 편향
- 평가 지표 선택에 따른 결론 변화
- 합성 데이터의 편향 증폭

6. 장점과 한계
7. 결과 또는 지표 해석
8. 자주 나오는 오개념
9. 객관식·주관식·서술형 확인 문제
