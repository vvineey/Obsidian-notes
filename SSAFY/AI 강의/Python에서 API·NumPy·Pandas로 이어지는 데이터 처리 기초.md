## 1. Python 핵심 문법

![[CS/AI/Python 핵심 문법#핵심 정리]]

### 1.1 변수와 기본 자료형

Python에서는 변수에 저장한 값에 따라 자료형이 결정된다.

| 자료형 | 의미 | 예시 |
| --- | --- | --- |
| `int` | 정수 | `27` |
| `float` | 실수 | `175.5` |
| `str` | 문자열 | `"AI"` |
| `bool` | 참과 거짓 | `True`, `False` |

자료형은 `type()`으로 확인하고, `isinstance(값, 자료형)`으로 특정 자료형인지 검사할 수 있다.

### 1.2 산술 연산자

| 문법 | 의미 | 주의점 |
| --- | --- | --- |
| `a + b` | 덧셈 | 문자열에서는 이어 붙이기로 동작한다. |
| `a - b` | 뺄셈 | 숫자 자료형에 사용한다. |
| `a * b` | 곱셈 | 문자열이나 리스트에서는 반복으로 동작할 수 있다. |
| `a / b` | 나눗셈 | 결과가 항상 실수다. |
| `a // b` | 몫 | 나눈 결과의 몫을 구한다. |
| `a % b` | 나머지 | 짝수·홀수 판별에도 사용한다. |
| `a ** b` | 거듭제곱 | `a ** 2`는 a의 제곱이다. |

제곱은 `x * x`로도 계산할 수 있지만, Python에서 거듭제곱을 표현하는 문법은 `x ** 2`이다.

### 1.3 형변환과 f-string

외부 파일이나 API에서 받은 숫자는 문자열일 수 있다. 계산 전에 자료형을 확인하고 필요한 형태로 변환해야 한다.

- `int("4000")` → 정수 `4000`
- `float("3.14")` → 실수 `3.14`
- `str(27)` → 문자열 `"27"`
- `int(3.99)` → 소수점 아래를 버린 정수 `3`

`int("3.14")`는 바로 변환할 수 없다. 먼저 `float("3.14")`로 바꾼 뒤 필요하면 `int()`를 적용한다.

문자열에 변수를 넣을 때는 `f"{name}님은 {age}살입니다."`처럼 f-string을 사용한다. 문자열과 숫자를 `+`로 바로 연결하면 `TypeError`가 발생한다.

### 1.4 list의 인덱싱과 슬라이싱

리스트는 순서가 있는 자료구조이며 인덱스는 0부터 시작한다.

- `values[0]`: 첫 번째 값
- `values[-1]`: 마지막 값
- `values[start:end]`: start부터 end 직전까지
- `values[:3]`: 처음부터 3개
- `values[-2:]`: 마지막 2개
- `values[::2]`: 한 칸씩 건너뛰며 선택
- `len(values)`: 원소 개수
- `sum(values)`: 원소 합계

슬라이싱의 끝 인덱스는 결과에 포함되지 않는다. `values[1:4]`는 인덱스 1, 2, 3의 값만 가져온다.

### 1.5 list 메서드와 반환값

리스트 메서드는 원본 변경 여부와 반환값을 함께 이해해야 한다.

| 문법 | 동작 | 원본 변경 | 반환값 |
| --- | --- | --- | --- |
| `append(x)` | 마지막에 추가 | O | `None` |
| `insert(i, x)` | 지정 위치에 추가 | O | `None` |
| `pop()` | 마지막 값 제거 | O | 제거한 값 |
| `pop(i)` | 지정 위치 값 제거 | O | 제거한 값 |
| `remove(x)` | 값으로 찾아 제거 | O | `None` |
| `sort()` | 원본 정렬 | O | `None` |
| `sorted(values)` | 정렬된 새 리스트 생성 | X | 새 리스트 |

`append`, `insert`, `remove`, `sort`의 결과를 원본 변수에 다시 대입하면 변수가 `None`이 될 수 있다. `values = values.append(x)`가 아니라 `values.append(x)`로 호출해야 한다.

### 1.6 dict와 안전한 값 조회

딕셔너리는 키와 값의 쌍으로 데이터를 저장한다.

- `person["name"]`: 키로 값 조회
- `person["job"] = "학생"`: 새로운 키 추가
- `person["age"] = 28`: 기존 값 수정
- `"age" in person`: 키 존재 여부 확인
- `list(person.keys())`: 키 목록 생성
- `person.get("hobby", "없음")`: 키가 없을 때 기본값 반환

반드시 존재하는 키는 `dict[key]`로 조회할 수 있다. 존재 여부가 불확실한 키는 `get()`을 사용하는 편이 안전하다.

### 1.7 중첩된 list와 dict

API의 JSON 데이터는 `list`와 `dict`가 여러 단계로 중첩된 형태가 많다.

`students[1]["scores"][0]`은 다음 순서로 읽는다.

1. `students[1]`: 두 번째 학생 딕셔너리
2. `["scores"]`: 해당 학생의 점수 리스트
3. `[0]`: 점수 리스트의 첫 번째 값

대괄호 안이 숫자면 리스트 인덱스이고 문자열이면 딕셔너리 키라고 생각하면 구조를 따라가기 쉽다.

### 1.8 조건문과 함수 반환

조건문은 위에서부터 검사하며 처음 참이 된 분기 하나만 실행한다. 범위를 나눌 때는 큰 기준부터 비교해야 중복 조건을 피할 수 있다.

함수에서 `return`이 실행되면 즉시 함수가 종료된다. 모든 분기에서 값을 반환한 뒤에 추가한 `return`은 실행되지 않는 코드가 된다.

### 1.9 반복문과 누적

반복 합계는 `total = 0`에서 시작해 `total += value`로 누적한다. 조건에 맞는 값만 모을 때는 빈 리스트를 만든 뒤 `append()`를 사용한다.

인덱스가 필요하면 `for i in range(len(values))`를 사용할 수 있다. 값 자체만 필요하다면 `for value in values`가 더 간결하다.

### 1.10 함수와 기본값 매개변수

함수는 입력을 받아 반복되는 작업을 하나의 이름으로 묶는다.

- `def`: 함수 정의
- 매개변수: 함수가 받을 입력
- `return`: 호출자에게 결과 반환
- 기본값 매개변수: 호출 시 값을 생략했을 때 사용할 값

예를 들어 `greet(name, greeting="안녕하세요")`는 두 번째 인수를 생략하면 기본 인사말을 사용한다.

평균을 계산하는 함수는 빈 리스트를 받으면 0으로 나누는 오류가 발생할 수 있으므로 실제 코드에서는 빈 입력 처리 여부를 정해야 한다.

### 1.11 문자열 문자 검사와 컴프리헨션

문자열은 `for ch in text`처럼 문자 단위로 순회할 수 있다. `ch.isdigit()`으로 숫자인지 검사한 뒤 `int(ch)`로 정수로 변환한다.

컴프리헨션은 반복문으로 새 자료구조를 만드는 축약 문법이다.

- 리스트 컴프리헨션: `[변환식 for 원소 in 반복가능객체]`
- 딕셔너리 컴프리헨션: `{키: 값 for 원소 in 반복가능객체}`
- 조건 포함: `[값 for 값 in 목록 if 조건]`

## 2. API와 JSON 데이터 처리

![[CS/AI/API와 JSON 데이터 처리#핵심 정리]]

### 2.1 요청과 응답

API 요청의 기본 흐름은 다음과 같다.

1. `requests.get(url, timeout=5)`로 GET 요청을 보낸다.
2. `response.raise_for_status()`로 HTTP 오류를 확인한다.
3. `response.json()`으로 JSON을 Python 객체로 변환한다.
4. 오류가 발생하면 예외 종류에 맞게 처리한다.

| 예외                | 의미                     |
| ----------------- | ---------------------- |
| `Timeout`         | 정해진 시간 안에 응답이 오지 않음    |
| `ConnectionError` | 서버 또는 네트워크 연결 실패       |
| `HTTPError`       | 4xx 또는 5xx 응답          |
| `JSONDecodeError` | 응답 본문을 JSON으로 변환할 수 없음 |

네트워크 요청은 언제든 실패할 수 있다. `timeout`과 예외 처리를 두고, 필요한 경우 실제 응답과 같은 구조의 대체 데이터를 준비한다.

### 2.2 JSON에서 필요한 값 추출

JSON 응답은 Python에서 주로 `list`와 `dict`의 중첩 구조가 된다.

- 이름: `user["name"]`
- 이메일: `user["email"]`
- 도시: `user["address"]["city"]`
- 회사: `user["company"]["name"]`
- 선택적인 값: `user.get("website")`

중첩 데이터는 바깥 구조부터 한 단계씩 확인해야 한다. `type()`, `len()`, `keys()`를 이용하면 현재 위치의 자료형과 구조를 파악하기 쉽다.

### 2.3 JSON을 DataFrame으로 변환

모든 필드를 그대로 표로 옮기기보다 분석에 필요한 필드만 같은 키 구조로 정리한다. 사용자마다 `name`, `email`, `city`, `company`를 가진 딕셔너리를 만들고 목록으로 모은 뒤 `pd.DataFrame(rows)`로 변환할 수 있다.

`df.info()`는 컬럼과 자료형, 결측 정보를 직접 출력하고 `None`을 반환한다. 따라서 `print(df.info())`가 아니라 `df.info()`만 호출하면 된다.

### 2.4 LLM 컨텍스트와 프롬프트

여러 문자열은 `"\n".join(...)`으로 줄바꿈해 하나의 컨텍스트로 합칠 수 있다. LLM에 데이터를 전달할 때는 원본 전체를 무조건 넣기보다 질문에 필요한 필드만 선택해야 한다.

프롬프트는 참고 자료와 질문을 명확히 구분한다. 컨텍스트의 목적은 모델이 질문과 관련된 정보를 놓치지 않도록 근거를 제공하는 것이다.

### 2.5 LLM 응답 파싱

LLM 응답도 중첩된 JSON 구조다.

- 답변: `result["choices"][0]["message"]["content"]`
- 전체 토큰 수: `result["usage"]["total_tokens"]`
- 종료 이유: `result["choices"][0]["finish_reason"]`

실제 서비스에서는 `choices`가 비어 있거나 예상 필드가 없을 가능성도 고려해야 한다. API 키는 코드에 직접 작성하지 않고 환경 변수에서 읽는다.

### 2.6 JSON 직렬화

`json.dumps(data, ensure_ascii=False)`는 Python 객체를 JSON 문자열로 바꾼다. `ensure_ascii=False`를 사용하면 한글을 `\uXXXX` 형태로 바꾸지 않고 읽을 수 있게 유지한다. 읽기 좋은 들여쓰기가 필요하면 `indent=2`를 추가한다.

## 3. NumPy 배열 연산

![[CS/AI/NumPy 배열 연산#핵심 정리]]

### 3.1 배열 생성과 벡터 연산

Python 리스트에서 `values * 2`는 리스트를 두 번 반복한다. NumPy 배열에서 `array * 2`는 각 원소에 2를 곱한다.

| 문법 | 의미 |
| --- | --- |
| `np.array([...])` | 배열 생성 |
| `np.arange(n)` | 0부터 n-1까지 생성 |
| `np.zeros(n)` | 0으로 채운 길이 n 배열 |
| `np.linspace(a, b, n)` | a부터 b까지 균등한 값 n개 생성 |

모양이 같은 두 배열을 곱하면 같은 위치의 원소끼리 연산한다. 반복문 없이 배열 전체를 계산하는 방식을 벡터 연산이라고 한다.

### 3.2 배열 통계

- 합계: `array.sum()` 또는 `np.sum(array)`
- 평균: `array.mean()` 또는 `np.mean(array)`
- 최댓값: `array.max()` 또는 `np.max(array)`
- 최솟값: `array.min()` 또는 `np.min(array)`
- 표준편차: `array.std()` 또는 `np.std(array)`

함수형 문법과 메서드형 문법이 모두 가능하다. 한 코드 안에서는 일관된 방식을 사용하는 편이 읽기 쉽다.

### 3.3 불리언 인덱싱

배열에 비교 연산을 적용하면 각 원소에 대한 `True`, `False` 배열이 만들어진다. `array[array >= 10000]`처럼 이 조건 배열을 인덱스로 사용하면 조건을 만족하는 값만 선택할 수 있다.

범위 조건은 `array[(array >= lower) & (array <= upper)]`처럼 각 조건을 괄호로 감싸고 `&`로 연결한다. NumPy와 Pandas 조건식에는 Python의 `and`, `or`를 사용하지 않는다.

### 3.4 정렬과 argsort

- `np.sort(array)`: 값을 오름차순으로 정렬한 새 배열
- `np.sort(array)[::-1]`: 정렬 결과를 뒤집은 내림차순 배열
- `np.argsort(array)`: 정렬된 값이 아니라 원본 인덱스의 순서 반환

`argsort`는 다른 배열이나 열을 같은 순서로 재배열해야 할 때 유용하다.

### 3.5 reshape, 전치, axis

`reshape`는 전체 원소 수를 유지하면서 배열의 모양을 바꾼다.

- `array.reshape(2, 3)`: 2행 3열로 변경
- `array.reshape(3, -1)`: 행을 3으로 정하고 열 수를 자동 계산
- `array.T`: 행과 열을 교환

2차원 배열에서 `axis=0`은 행 축을 따라 계산해 열별 결과를 만들고, `axis=1`은 열 축을 따라 계산해 행별 결과를 만든다.

### 3.6 브로드캐스팅

브로드캐스팅은 모양이 다른 배열을 일정한 규칙에 따라 확장해 연산하는 기능이다. `array[:, np.newaxis]`는 1차원 `(n,)` 배열에 축을 하나 추가해 `(n, 1)`로 바꾼다.

브로드캐스팅 오류가 발생하면 계산식보다 먼저 두 배열의 `shape`를 확인해야 한다.

## 4. Pandas 데이터 처리

![[CS/AI/Pandas 데이터 처리#핵심 정리]]

### 4.1 Series와 DataFrame

- `Series`: 하나의 열과 같은 1차원 구조
- `DataFrame`: 여러 행과 열을 가진 2차원 표

딕셔너리의 각 키가 컬럼 이름이 되고 값의 배열이 해당 열의 데이터가 된다. 기존 컬럼을 연산해 `df["매출"] = df["단가"] * df["수량"]`처럼 파생 컬럼을 만들 수 있다.

### 4.2 데이터 구조 확인

데이터를 받으면 바로 필터링하기 전에 구조부터 확인한다.

| 문법 | 확인하는 내용 |
| --- | --- |
| `df.head(n)` | 위에서 n행 |
| `df.tail(n)` | 아래에서 n행 |
| `df.shape` | 행과 열의 개수 |
| `df.info()` | 컬럼, 자료형, 결측치 |
| `df.describe()` | 숫자 컬럼의 통계 |
| `df.dtypes` | 컬럼별 자료형 |
| `df["컬럼"].value_counts()` | 값별 빈도 |

`df.shape`는 `(행 수, 열 수)` 튜플이므로 `rows, columns = df.shape`처럼 구조 분해 할당할 수 있다.

### 4.3 조건 필터링

기본 필터 형태는 `df[조건]`이다.

- 단일 조건: `df[df["지역"] == "서울"]`
- 복합 AND: `(조건1) & (조건2)`
- 복합 OR: `(조건1) | (조건2)`
- 문자열 포함: `str.contains("라떼")`
- 문자열 시작: `str.startswith("카페")`
- 후보 목록 포함: `isin(["아메리카노", "카페라떼"])`

각 조건을 괄호로 감싸지 않으면 연산자 우선순위 때문에 오류가 발생하거나 의도와 다른 결과가 나올 수 있다.

### 4.4 상위·하위 데이터와 행·열 선택

- `df.nlargest(n, "컬럼")`: 해당 컬럼 기준 상위 n행
- `df.nsmallest(n, "컬럼")`: 해당 컬럼 기준 하위 n행
- `df.loc[행 조건, "열 이름"]`: 라벨과 조건으로 선택
- `df.iloc[행 위치, 열 위치]`: 정수 위치로 선택

조건에 따라 값을 수정할 때는 `loc`를 사용한다. 원본을 보존해야 한다면 먼저 `df.copy()`로 사본을 만든다.

### 4.5 groupby와 agg

`groupby`는 같은 값을 가진 행을 묶은 뒤 그룹별 통계를 계산한다.

- `df.groupby("지역")["매출"].sum()`: 지역별 총매출
- `df.groupby("메뉴")["단가"].mean()`: 메뉴별 평균 단가
- `df.groupby("지역").size()`: 지역별 전체 행 수

`size()`는 결측치와 관계없이 그룹의 전체 행 수를 센다. `count()`는 선택한 컬럼의 결측값을 제외하고 센다.

여러 통계를 한 번에 만들 때는 `agg()`를 사용한다. 그룹 합계가 원본 전체 합계와 일치하는지 비교하면 집계 과정의 누락을 검증할 수 있다.

### 4.6 다중 groupby와 reset_index

`df.groupby(["지역", "메뉴"])["매출"].sum()`처럼 여러 기준으로 그룹화할 수 있다. 결과는 그룹 기준이 계층형 인덱스인 `MultiIndex` 구조가 된다.

`reset_index()`는 인덱스로 이동한 그룹 기준을 다시 일반 컬럼으로 되돌린다.

### 4.7 pivot_table

`pivot_table`은 한 기준을 행으로, 다른 기준을 열로 펼쳐 교차 집계표를 만든다.

- `index`: 세로 방향 기준
- `columns`: 가로 방향 기준
- `values`: 집계할 값
- `aggfunc`: 사용할 집계 함수

`groupby`와 `pivot_table`은 같은 집계를 표현할 수 있지만 결과 모양이 다르다. `groupby`는 세로로 긴 구조에 가깝고 `pivot_table`은 항목 간 비교가 쉬운 교차표 형태다.

### 4.8 분석 결과 구성

- `Series.idxmax()`: 가장 큰 값을 가진 인덱스 반환
- `value_counts()`: 값별 개수를 기본 내림차순으로 반환
- 조건 필터 뒤 `mean()`: 특정 집단의 평균 계산
- `nlargest()` 뒤 열 선택: 상위 행에서 필요한 컬럼만 추출

분석 결과를 만들 때는 계산값뿐 아니라 대상 조건, 집계 기준, 결과 컬럼이 요구사항과 일치하는지 확인한다.
