# 일반화와 과적합

## 핵심 정리

> [!definition]
> 일반화는 모델이 학습에 사용하지 않은 새로운 데이터에서도 좋은 성능을 유지하는 능력이다. 과적합은 모델이 학습 데이터의 잡음과 우연한 특징까지 외워 학습 성능은 높지만 새로운 데이터의 성능이 낮아진 상태다. 과소적합은 모델이 너무 단순해 중요한 패턴도 충분히 학습하지 못한 상태다.

## 왜 필요한가

학습 오차만 보면 복잡한 모델이 항상 좋아 보일 수 있다. 그러나 머신러닝 모델은 학습 데이터를 다시 맞히기 위해 만드는 것이 아니라 앞으로 들어올 데이터를 예측하기 위해 만든다. 따라서 모델 선택의 기준은 학습 점수가 아니라 일반화 성능이어야 한다.

## 성능 패턴

| 상태 | 학습 성능 | 검증·테스트 성능 |
| --- | --- | --- |
| 과소적합 | 낮음 | 낮음 |
| 적절한 학습 | 높음 | 높음 |
| 과적합 | 매우 높음 | 낮음 |

## 동작 흐름

모델 복잡도 증가 → 학습 오차 감소 → 검증 오차 감소 → 적절한 복잡도 도달 → 잡음까지 학습 → 검증 오차 증가

## 일반화 성능 확인 방법

- 학습에 사용하지 않은 검증 데이터에서 성능을 측정한다.
- 여러 모델과 설정은 검증셋 또는 교차검증으로 비교한다.
- 모든 선택이 끝난 뒤 별도로 보관한 테스트 데이터에서 최종 평가한다.
- 학습 성능과 검증 성능의 차이를 함께 확인한다.

## 자주 하는 실수

- 학습 점수가 높으면 좋은 모델이라고 판단한다.
- 테스트 데이터를 반복 확인하며 모델을 수정한다.
- 새로운 데이터의 성능 저하를 모두 과적합으로 단정한다.
- 교차검증 평균만 보고 fold별 변동을 확인하지 않는다.
- 데이터 분포가 학습 시점과 달라진 문제를 과적합과 혼동한다.
