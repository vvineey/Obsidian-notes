# Python 핵심 문법

## 핵심 정리

> [!definition]
> Python에서는 자료형과 자료구조로 데이터를 표현하고, 조건문·반복문·함수로 처리 흐름을 구성한다. AI API와 데이터 분석 코드를 이해하려면 변수와 형변환뿐 아니라 `list`·`dict`의 중첩 구조, 함수의 반환값, 객체를 변경하는 메서드의 동작을 알아야 한다.

## 왜 필요한가

API 응답은 중첩된 `list`와 `dict`로 다루며, 데이터 정제 과정은 조건문과 반복문, 함수로 구성된다. NumPy와 Pandas도 Python 문법 위에서 동작하므로 기본 문법을 정확히 알아야 라이브러리 코드를 읽고 오류를 해결할 수 있다.

## 핵심 문법

| 구분 | 문법 | 핵심 |
| --- | --- | --- |
| 자료형 | `int`, `float`, `str`, `bool` | 값의 종류를 구분한다. |
| 형변환 | `int()`, `float()`, `str()` | 외부 입력을 계산 가능한 형태로 바꾼다. |
| 리스트 | 인덱싱, 슬라이싱, 메서드 | 순서가 있는 데이터를 다룬다. |
| 딕셔너리 | 키 조회, `get()`, `in` | 이름이 붙은 데이터를 다룬다. |
| 제어 흐름 | `if`, `for`, `break`, `continue` | 조건과 반복을 표현한다. |
| 함수 | `def`, 매개변수, 기본값, `return` | 로직을 재사용하고 결과를 반환한다. |
| 컴프리헨션 | list·dict comprehension | 변환과 필터를 간결하게 표현한다. |

## 동작에서 구분할 것

- `sort()`는 원본을 변경하고 `None`을 반환한다.
- `sorted()`는 원본을 유지하고 새 리스트를 반환한다.
- `pop()`은 원본을 변경하면서 제거한 값을 반환한다.
- `return`이 실행되면 함수는 즉시 종료된다.
- `x ** 2`는 Python의 거듭제곱 문법이다.
- f-string은 문자열과 값을 안전하게 조합한다.

## 자주 하는 실수

- `append()`나 `sort()`의 반환값을 원본 변수에 다시 대입한다.
- 문자열 숫자를 형변환하지 않고 계산한다.
- 중첩된 `list`와 `dict`의 접근 순서를 혼동한다.
- 빈 입력을 고려하지 않고 평균을 계산한다.
- 이미 `return`한 뒤에 실행되지 않는 코드를 남긴다.
