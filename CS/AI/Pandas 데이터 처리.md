# Pandas 데이터 처리

## 핵심 정리

> [!definition]
> Pandas는 `Series`와 `DataFrame`을 이용해 표 형태의 데이터를 조회하고 정제하고 집계하는 라이브러리다. 분석을 시작할 때는 값 자체보다 데이터의 크기, 컬럼, 자료형, 결측치와 분포를 먼저 확인해야 한다.

## 왜 필요한가

API, CSV, 데이터베이스에서 받은 데이터는 대부분 행과 열 구조로 다룬다. Pandas는 필요한 행과 열을 선택하고 조건에 따라 필터링하며 그룹별 통계를 만드는 일관된 인터페이스를 제공한다.

## 기본 흐름

데이터 읽기 → 구조 확인 → 조건 필터 → 필요한 행·열 선택 → 그룹 집계 → 결과 검증

## 구조 확인

| 문법 | 확인하는 내용 |
| --- | --- |
| `head`, `tail` | 위·아래 일부 행 |
| `shape` | 행과 열의 개수 |
| `info` | 컬럼, 자료형, 결측치 |
| `describe` | 숫자 컬럼 통계 |
| `dtypes` | 컬럼별 자료형 |
| `value_counts` | 값별 빈도 |

## 선택과 필터

- `df[조건]`: 조건이 참인 행 선택
- `&`, `|`: 복합 조건 연결
- `str.contains`, `str.startswith`, `isin`: 문자열과 목록 조건
- `loc`: 라벨과 조건으로 행·열 선택 및 수정
- `iloc`: 정수 위치로 행·열 선택
- `nlargest`, `nsmallest`: 상위·하위 행 추출

복합 조건은 각 조건을 괄호로 감싸야 한다. 원본을 보존해야 하는 수정 작업은 `copy()`로 사본을 만든 뒤 수행한다.

## 그룹 집계

- `groupby`: 같은 값을 가진 행을 그룹으로 묶는다.
- `size`: 결측치와 관계없이 전체 행 수를 센다.
- `count`: 선택한 컬럼에서 결측값을 제외하고 센다.
- `agg`: 여러 통계를 한 번에 계산한다.
- `reset_index`: 그룹 기준을 일반 컬럼으로 되돌린다.
- `pivot_table`: 한 기준을 행, 다른 기준을 열로 펼쳐 교차 집계한다.

## 결과 검증

그룹별 합계의 전체 합이 원본 합계와 일치하는지 확인하면 누락 여부를 검증할 수 있다. 필터 결과는 선택한 조건이 모든 행에서 참인지 확인하고, 피벗 결과는 행·열 기준과 전체 합을 함께 점검한다.

## 자주 하는 실수

- 조건식에 `and`, `or`를 사용한다.
- 복합 조건의 괄호를 생략한다.
- 원본 DataFrame을 의도치 않게 수정한다.
- `info()`가 DataFrame을 반환한다고 생각한다.
- `size()`와 `count()`의 차이를 구분하지 않는다.
- 집계 결과를 원본과 비교하지 않는다.
