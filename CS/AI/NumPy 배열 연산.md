# NumPy 배열 연산

## 핵심 정리

> [!definition]
> NumPy의 `ndarray`는 같은 자료형의 값을 다차원 구조로 저장하고 배열 전체에 연산을 적용한다. 벡터 연산, 불리언 인덱싱, 형태 변환, 브로드캐스팅, 축별 집계는 AI와 데이터 분석에서 수치 데이터를 처리하는 핵심 도구다.

## 왜 필요한가

Python 반복문으로 수치 데이터를 하나씩 처리하면 코드가 길어지고 실행 비용이 커진다. NumPy는 배열 단위 연산을 제공해 대량의 수치 데이터를 간결하고 효율적으로 처리한다.

## 배열 생성

| 문법 | 역할 |
| --- | --- |
| `np.array(values)` | 기존 값으로 배열 생성 |
| `np.arange(n)` | 0부터 n-1까지 생성 |
| `np.zeros(n)` | 0으로 채운 배열 생성 |
| `np.linspace(a, b, n)` | 구간에 균등한 값 n개 생성 |

## 핵심 연산

- 벡터 연산: 배열 전체 또는 같은 위치의 원소끼리 계산한다.
- 불리언 인덱싱: `array[조건]`으로 조건을 만족하는 값만 선택한다.
- 정렬: `np.sort()`는 정렬된 값을, `np.argsort()`는 정렬 순서의 인덱스를 반환한다.
- 형태 변환: `reshape()`는 원소 수를 유지하면서 배열 모양을 바꾼다.
- 전치: `.T`는 행과 열을 교환한다.

## axis

- `axis=0`: 행 축을 따라 계산해 열별 결과를 만든다.
- `axis=1`: 열 축을 따라 계산해 행별 결과를 만든다.

## 브로드캐스팅

브로드캐스팅은 모양이 다른 배열을 일정한 규칙으로 확장해 연산한다. `array[:, np.newaxis]`는 `(n,)` 배열을 `(n, 1)`로 바꾼다. 연산 오류가 발생하면 먼저 두 배열의 `shape`를 확인한다.

## 자주 하는 실수

- Python 리스트의 반복과 NumPy의 원소별 연산을 혼동한다.
- 복합 조건에 `and`, `or`를 사용한다.
- `reshape` 전후의 원소 수를 다르게 지정한다.
- `axis=0`과 `axis=1`의 결과 방향을 혼동한다.
- 브로드캐스팅 가능 여부를 확인하지 않고 연산한다.
