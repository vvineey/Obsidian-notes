# 데이터 시각화

## 핵심 정리

> [!definition]
> 데이터 시각화는 숫자와 범주를 그래프로 표현해 차이, 추세, 분포, 관계와 이상치를 발견하는 과정이다. 분석 질문에 맞는 차트를 선택해야 하며, Matplotlib은 세부 구성을 담당하고 Seaborn은 DataFrame 기반의 통계 집계와 시각화를 간결하게 지원한다.

## 왜 필요한가

표만으로는 데이터가 어디에 몰려 있는지, 그룹 간 차이가 얼마나 큰지, 값 사이에 어떤 관계가 있는지 빠르게 판단하기 어렵다. 시각화는 데이터 품질 문제를 찾고 다음 분석이나 전처리 방향을 결정하는 근거가 된다.

## 차트 선택 기준

| 질문 | 차트 | 해석 대상 |
| --- | --- | --- |
| 범주별 값이 얼마나 다른가 | 막대그래프 | 그룹 간 크기 |
| 시간에 따라 어떻게 변하는가 | 꺾은선그래프 | 추세와 변화점 |
| 두 수치가 함께 움직이는가 | 산점도 | 관계, 군집, 이상치 |
| 값이 어디에 몰려 있는가 | 히스토그램 | 빈도와 분포 형태 |
| 그룹별 분포가 어떻게 다른가 | 박스플롯 | 중앙값, 사분위수, 이상치 |
| 여러 수치 변수의 관계는 어떤가 | 히트맵 | 상관계수 패턴 |

## 동작 흐름

분석 질문 정의 → 필요한 컬럼 선택 → 차트 유형 선택 → 제목·축·범례 표시 → 분포와 관계 해석 → 추가 분석 또는 전처리 결정

## Matplotlib과 Seaborn

- Matplotlib의 `Figure`는 전체 그림이고 `Axes`는 개별 그래프 영역이다.
- `plt.subplots()`로 여러 Axes를 만들고 `axes[행, 열]`로 접근한다.
- `plt.bar()`는 전달된 값을 그대로 그린다.
- `sns.barplot()`은 원본 데이터를 받아 범주별 평균을 계산해 그린다.
- Seaborn도 Matplotlib 위에서 동작하므로 제목, 축, 폰트 설정을 함께 사용할 수 있다.

## 자주 하는 실수

- 질문과 맞지 않는 차트를 선택해 분포와 비교의 의미를 혼동한다.
- 축 이름과 단위를 생략해 값의 의미를 알 수 없게 만든다.
- 서브플롯에서 `plt`와 개별 `axes`를 혼용해 의도하지 않은 위치에 그린다.
- 범주별 개수를 보여주는 `countplot`과 평균을 보여주는 `barplot`을 혼동한다.
- 상관관계를 원인과 결과로 해석한다.
- 결측치를 정리하지 않고 히스토그램이나 `pairplot`에 전달한다.
