# 비지도학습

## 핵심 정리

> [!definition]
> 비지도학습은 정답 라벨이 없는 데이터에서 유사성, 군집, 저차원 구조와 이상 패턴을 발견하는 머신러닝 방법이다. 정해진 정답을 예측하는 대신 데이터 자체를 설명하는 구조나 새로운 표현을 만든다.

## 왜 필요한가

현실의 데이터에는 정답이 붙어 있지 않은 경우가 많다. 고객 유형, 문서 주제, 이상 거래처럼 사전에 명확한 범주를 정의하기 어려운 문제에서는 데이터 안에 반복되는 구조를 먼저 발견해야 한다.

## 대표 작업

| 작업 | 목적 |
| --- | --- |
| 클러스터링 | 비슷한 데이터를 같은 그룹으로 묶음 |
| 차원 축소 | 많은 특성을 적은 차원으로 표현 |
| 이상치 탐지 | 일반적인 패턴에서 벗어난 데이터 탐색 |
| 표현 학습 | 데이터의 핵심 특징을 새로운 벡터로 변환 |

## 동작 흐름

라벨 없는 데이터 준비 → 특성 선택과 스케일링 → 유사도 또는 목적 함수 정의 → 구조 탐색 → 결과 시각화와 해석 → 현실 문제에서 의미 검증

## 자주 하는 실수

- 비지도학습 결과를 객관적인 정답이라고 생각한다.
- 클러스터링과 분류를 같은 작업으로 이해한다.
- 스케일링하지 않고 서로 다른 단위의 특성을 거리 계산에 사용한다.
- 알고리즘이 붙인 군집 번호에 순서나 의미가 있다고 해석한다.
- 수학적으로 분리된 군집이 현실적으로도 의미 있다고 단정한다.
- 정답이 없다는 이유로 결과 검증이 필요 없다고 생각한다.
