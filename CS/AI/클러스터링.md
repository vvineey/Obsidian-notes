# 클러스터링

## 핵심 정리

> [!definition]
> 클러스터링은 라벨이 없는 데이터에서 서로 유사한 데이터를 같은 군집으로 묶는 비지도학습 방법이다. 좋은 군집은 군집 내부 데이터의 거리는 작고 서로 다른 군집 사이 거리는 크다. 결과는 특성, 스케일, 거리 함수와 알고리즘 선택에 따라 달라진다.

## 왜 필요한가

고객 유형이나 문서 주제처럼 미리 정답 범주를 만들기 어려운 데이터에서 자연스럽게 반복되는 그룹을 발견할 수 있다. 발견한 군집은 데이터 탐색, 고객 세분화, 이상치 탐지와 후속 분석에 활용할 수 있다.

## K-means

K-means는 군집 수 K를 먼저 정하고 각 데이터와 중심점 사이의 제곱 거리를 최소화한다.

**초기 중심점 설정 → 가장 가까운 중심점에 데이터 할당 → 군집별 중심점 재계산 → 재할당과 갱신 반복**

초기 중심점에 따라 결과가 달라질 수 있으므로 여러 초기값으로 반복 실행하는 것이 중요하다.

## 계층적 군집

병합형 계층적 군집은 각 데이터를 하나의 군집으로 시작해 가장 가까운 두 군집을 반복해서 합친다. 결합 순서와 거리는 덴드로그램으로 표현한다.

| Linkage | 군집 간 거리 |
| --- | --- |
| Single | 가장 가까운 데이터 쌍의 거리 |
| Complete | 가장 먼 데이터 쌍의 거리 |
| Average | 모든 데이터 쌍 거리의 평균 |

## 자주 하는 실수

- K-means의 K를 데이터가 자동으로 정해 준다고 생각한다.
- 중심점이 반드시 실제 데이터라고 생각한다.
- K-means가 항상 전체 최적해를 찾는다고 생각한다.
- 초기값을 한 번만 사용하고 결과를 확정한다.
- 계층적 군집은 군집 수를 결정할 필요가 없다고 생각한다.
- 덴드로그램을 자르는 높이와 linkage에 따라 결과가 달라지는 점을 놓친다.
- 이상치와 스케일이 거리 계산에 미치는 영향을 무시한다.
