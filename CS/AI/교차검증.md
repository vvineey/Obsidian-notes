# 교차검증

## 핵심 정리

> [!definition]
> 교차검증은 데이터를 여러 부분으로 나누고 학습과 검증 역할을 번갈아 수행해 모델의 일반화 성능을 추정하는 방법이다. K-fold 교차검증에서는 각 데이터를 한 번씩 검증에 사용하고 나머지 K-1개 fold로 학습한 결과를 평균한다.

## 왜 필요한가

검증 데이터를 한 번만 나누면 어떤 표본이 선택됐는지에 따라 평가 결과가 크게 달라질 수 있다. 교차검증은 여러 분할에서 성능을 반복 측정하여 모델과 하이퍼파라미터를 비교할 더 안정적인 기준을 제공한다.

## 동작 흐름

데이터를 K개 fold로 분할 → 하나를 검증용으로 선택 → 나머지로 학습 → 검증 성능 계산 → 검증 fold 변경 → K번 결과 평균

## 평균 검증 오차

$$
CV(K)=\frac{1}{K}\sum_{k=1}^{K}Error_k
$$

회귀는 MSE나 RMSE, 분류는 정확도·F1·로그 손실처럼 문제에 맞는 평가 지표를 각 fold에서 계산한 뒤 평균한다.

## 주요 방법

| 방법 | 특징 |
| --- | --- |
| 홀드아웃 | 데이터를 한 번만 나누어 빠르게 검증 |
| K-fold | K개 fold가 한 번씩 검증 역할 수행 |
| LOOCV | 데이터 하나씩 검증하며 총 $n$번 반복 |

## 자주 하는 실수

- 테스트 데이터를 교차검증에 포함한다.
- 전체 데이터에서 전처리 기준을 먼저 계산한다.
- 교차검증 점수를 최종 테스트 점수로 해석한다.
- 교차검증이 과적합을 자동으로 제거한다고 생각한다.
- K가 클수록 무조건 정확한 평가라고 생각한다.
- 모델을 선택한 뒤 전체 학습 데이터로 다시 학습하지 않는다.
