# EDA와 데이터 전처리

## 핵심 정리

> [!definition]
> EDA는 분석이나 모델링 전에 데이터의 구조, 분포, 결측치, 이상치와 변수 관계를 탐색하는 과정이다. 데이터 전처리는 EDA에서 발견한 문제를 바탕으로 값을 채우거나 제거하고, 스케일과 표현을 변환해 분석 가능한 형태로 만드는 과정이다. 특성 공학은 기존 컬럼을 조합하거나 구간화해 분석 질문에 더 적합한 새 정보를 만드는 작업이다.

## 왜 필요한가

모델은 입력 데이터에 있는 오류와 편향을 스스로 구분하지 못한다. 결측치, 비정상적인 값, 중복 정보와 잘못된 자료형을 그대로 사용하면 통계 결과와 모델 성능이 왜곡될 수 있다. 먼저 데이터를 관찰하고 문제의 원인을 생각한 뒤 처리 방법을 선택해야 한다.

## 동작 흐름

분석 목적 설정 → `shape`, `info`, `describe`로 구조 확인 → 결측치·이상치 탐색 → 분포와 관계 시각화 → 그룹 집계 → 처리 기준 결정 → 사본에서 전처리 → 파생 특성 생성 → 결과 재검증

## 결측치 처리

- 수치형 데이터는 평균이나 중앙값을 고려한다.
- 이상치가 크거나 분포가 치우쳤다면 중앙값이 평균보다 안정적이다.
- 범주형 데이터는 최빈값을 사용할 수 있다.
- 그룹마다 분포가 다르면 전체 통계보다 그룹별 통계로 채우는 편이 의미를 더 잘 보존할 수 있다.
- category 자료형에 새 값을 채울 때는 `cat.add_categories()`로 범주를 먼저 등록한다.
- 제거할 때는 `dropna()`로 생기는 데이터 손실을 확인한다.

## 이상치 처리

IQR 방식은 `Q1`, `Q3`와 `IQR = Q3 - Q1`을 이용한다. 일반적인 후보 범위는 `Q1 - 1.5 × IQR`부터 `Q3 + 1.5 × IQR`까지다. 이상치라고 해서 무조건 삭제하지 않고 입력 오류인지 실제로 드문 값인지 먼저 판단한다.

`clip()`으로 값을 상한이나 하한에 맞출 수 있다. 보정된 컬럼을 이용하는 파생 컬럼이 있다면 함께 다시 계산해야 한다.

## 변환과 특성 공학

| 방법 | 목적 | 대표 문법 |
| --- | --- | --- |
| Min-Max 정규화 | 값을 0~1 범위로 변환 | `(x - min) / (max - min)` |
| 범주 인코딩 | 문자열 범주를 숫자로 표현 | `map`, `cat.codes` |
| 동일 폭 구간화 | 값의 범위를 같은 간격으로 나눔 | `pd.cut` |
| 동일 빈도 구간화 | 각 구간의 데이터 수를 비슷하게 나눔 | `pd.qcut` |
| 컬럼 조합 | 여러 정보를 하나의 의미로 결합 | 산술 연산, `apply` |

## Pandas에서 자주 쓰는 문법

- `isnull().sum()`: 컬럼별 결측치 개수
- `fillna()`: 결측치 대체
- `quantile()`: 분위수 계산
- `clip()`: 상한과 하한 기준으로 값 제한
- `groupby().agg()`: 그룹별 여러 통계량 계산
- `pivot_table()`: 두 기준의 교차 집계
- `reset_index()`: 그룹 인덱스를 일반 컬럼으로 변환
- `sort_values()`: 분석 결과 정렬
- `drop()`: 불필요하거나 중복된 컬럼 제거
- `apply()`: 각 값에 사용자 정의 함수 적용

## 자주 하는 실수

- 원본 DataFrame을 복사하지 않고 바로 수정한다.
- `fillna`, `drop`, `clip`이 항상 원본을 바꾼다고 생각하고 결과를 재할당하지 않는다.
- 평균이 항상 적절한 결측치 대체값이라고 생각한다.
- `mode()`가 단일 값이 아니라 Series를 반환한다는 점을 놓친다.
- `cut`의 동일 폭과 `qcut`의 동일 빈도를 반대로 이해한다.
- 같은 값이 많아 `qcut`의 구간 경계가 중복될 수 있음을 고려하지 않는다.
- 전체 데이터를 이용해 전처리 기준을 계산한 뒤 모델을 평가해 데이터 누수를 만든다.
- EDA에서 확인한 그룹 차이를 인과관계로 단정한다.
